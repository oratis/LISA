# Reach-out 章程：Lisa 什么时候可以主动找你

日期：2026-10-02。状态：**生效**，随 [升级方案](PLAN_ALWAYS_ON_UPGRADE_2026-09-30.md) W3 一起落地。

这份章程取代 [AUTONOMY_ROADMAP](AUTONOMY_ROADMAP.md) 里"不让她主动联系用户、发消息、推送通知"那条非目标。那条非目标本身写明了扩张边界的前提：要有单独的路线图，以及明确的用户授权流程。本章程就是这两样东西。

## 1. 原则

1. **主动是为了你交代的事。** 首先是你自己设的任务、routine 和 watcher 的结果，其次是需要你决定的审批。Lisa 自己的欲望和反思笔记，默认只在 App 内展示。
2. **你握着旋钮。** 主动度分四档（关 / 低 / 中 / 高），可以按来源逐个开关，有免打扰时段，还有每日预算。
3. **不打扰是默认。** 无事可报就不说话。任何一条未经请求的消息都要先过价值闸门。
4. **只读的主动通道。** Lisa 自发的研究、欲望推进和 Reve 只能用只读工具，外加写她自己的 soul、记忆和知识库。任何对外副作用，都必须转成你授权的任务，再经过 Warden。
5. **每条主动消息都标明来自 Lisa。** 绝不冒充真人，也绝不借主动性向你索取更多数据。

## 2. 来源与默认待遇

| 来源 | 例子 | 是否经请求 | 默认待遇 |
|---|---|---|---|
| `approval` | Warden 需要你批准一个动作 | — | 总是投递（App 内 + 推送），免打扰时段也投递 |
| `task` / `watcher` | 你的 routine 跑完、盯的网页命中 | 是 | 不占每日预算；尊重"关"档和免打扰时段（推送延后） |
| `mail` | 重要邮件提醒、每日摘要 | 否 | 过价值闸门，占预算 |
| `brief` | 知识库每日简报 | 否 | 过价值闸门，占预算 |
| `advisor` | coding agent 卡住、冲突 | 否 | 过价值闸门，占预算（沿用 advisor 评分） |
| `idle` | "while you were away" 笔记 | 否 | App 内；推送占预算 |
| `desire` | Lisa 自己的欲望进展 | 否 | 只在 App 内，除非你单独开启推送 |
| `system` | 安全事件、主机离线 | — | `critical` 总是投递 |

## 3. 控制项

- **主动度**：关 / 低 / 中 / 高，默认"中"。"关"表示只在 App 内展示，不推送；审批和 `critical` 例外。
- **每日未经请求预算**：低 1 条，中 3 条，高 8 条。超出后只进 App 内，或延后投递。预算按本地时区零点重置。
- **免打扰时段**：默认 22:00–08:00。期间推送延后，或者降为静默（取决于推送通道是否支持）。
- **按来源开关**：上表每一行都可以单独关掉。
- **渠道偏好**：App 内、推送、IM 渠道，可以分别选择。

## 4. 价值闸门

未经请求的消息，先按 advisor 的现有评分打分：紧急度 × 可行动性 × 驳回衰减。分数不到门槛的不推送。你对每条消息的"有用 / 忽略"反馈会回写评分，同类消息被忽略多了，权重就自动降低。同一事件用 `dedupeKey` 在时间窗内去重。

## 5. 红线

以下情况一律拒绝投递，并记录在案：

- 目的是让你"再连接一个账号或数据源"的主动消息；
- 施加情绪压力、制造愧疚或依赖的措辞；
- 不能标明来自 Lisa 的消息；
- 一次授权被当成长期授权，比如批准过一次发信，就用同样的方式继续给别人发。

## 6. 合规模块

以下几项默认关闭，按地区或用户需要开启：

- 长时使用提醒，例如每 120 分钟一次。对应中国《人工智能拟人化互动服务管理暂行办法》的提醒要求。
- 过度依赖提示。
- 对话开始时声明 AI 身份。纽约法规和加州 SB 243 适用于可能被误认为真人的场景。Lisa 的每条主动消息本来就标明来自 Lisa。

## 7. 度量

投递台账只记来源、类别、标题的哈希和长度，不记正文。它用来计算每日预算和"主动消息有用率"，即被采纳、点击或标为有用的消息占全部主动消息的比例。初始目标 ≥ 60%。

## 8. 实现

- 闸门：`reachOut()`，位于 `src/reachout/`。所有主动投递都必须经过它，绕开它是缺陷。
- 设置与台账：`<lisaHome>/reachout/`；API 为 `/api/reachout/*`。
- 只读主动通道由 `autonomousSubset` 保证，并有回归测试：一旦这个子集里出现能发送、发布、执行或写 Lisa home 之外文件的工具，测试就会失败。
- Warden 对 `origin: autonomy` 的系统规则是：除 read 与 self 以外一律拒绝。
