## 调研口径

- 截止日期：2026-10-24，Asia/Shanghai。外部网页是当日可访问版本，不是永久快照。
- 顺序：同步代码 → 阅读历史研究 → 重新检索和打开官方原文 → 检查官方公开界面示意 → 对照当前代码 → 形成方案。
- **[官]**：官方正文说明；证明供应方公开承诺，不证明可靠性、所有账号可用或内部实现经独立审计。
- **[视]**：本次浏览器查看了官方公开页面中的截图或交互示意；不是登录后的产品实测。
- **[码]**：当前仓库代码、接口契约、测试或发布记录；不自动等于已部署或 App Store 已发布。
- **[建议]**：从证据推导的 LISA 产品／工程设计，尚未实施。
- **[待验]**：未拿到足够证据，不填“支持”或“没有”。

本次没有登录竞品、申请邀请码、购买订阅、连接私人账号或执行真实任务；没有测量竞品成功率、成本、时延，也没有读取 LISA 生产后台。研究完整覆盖定位、获客与首用、三端界面、任务生命周期、成果、自动化、连接器、记忆、审批、通知、运行位置、商业化和限制；实测缺口列在方案的验证清单里。

## 可重复核验

1. 按 sources.md 打开直接来源，先核对正文日期，再看当前可用范围。
2. 历史材料只用于提出问题；本月发生变化的条目以本次来源为准。无法重验的新闻、安全事件、价格、用户量，不带入本次方案的事实前提。
3. 代码证据固定在 4115c1a01637ed96bebdc558964d923e0261ed72，包版本 0.28.1；基线盘点中的源码链接均指向该提交。后续实施时请重新核对目标版本。
4. 同一来源的长文不全文复制；这里只保留必要的事实摘要和原创分析。
5. 这是一轮研究与设计交付，不是实现完成记录；新规格通过实施 PR 才能成为现行行为。
