## 怎么读

- **标签**：[官方] 一手材料（官方博客、文档、帮助中心、条款、商店元数据）；[媒体] 主流媒体与研究机构；[实测] 上手评测；[社区] 论坛、HN、X、商店评论；[推测] 作者推断。
- **边界**：只做了公开资料研究。没有登录任何产品，没有使用邀请码，没有付费实测。Cue 和 Dots 发布时间离调研只有一两天，实测样本少，价格与平台信息还在变。
- **冲突**：同一事实在不同来源说法不一时，备忘里原样并列，不替读者裁决。例如 Muse 的下载量，各数据商给出 230 万到 430 万。
- **关于 LISA 的表述**：各备忘的"对 LISA 的启示"一节，是研究员根据一段简短的 LISA 介绍写的。与 [能力盘点](lisa-capability-inventory.md) 或综述冲突时，以后两者为准。已知的一处已更正：云端生产模型自 v0.27.1 起是 Gemini 2.5 Flash，不再是 GLM。
- **时效**：所有内容截至 2026-09-30。这些产品每周都在变，引用前请回到原始来源核对。
