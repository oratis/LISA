## Product review

The Muse-inspired changes improve first use and connection safety: cloud-first onboarding, editable task starters, separate Mac/Cloud credentials, request cancellation and history reset on connection changes. Streaming, history decoding and authenticated images have subsequent fixes. These are useful personal-assistant foundations, not evidence of a fully autonomous hosted computer.

| Finding | Evidence and disposition |

## Binary changes

- Remove `AppStore.sync()` and the Restore purchases button. **Refresh credit balance** reads `/api/billing/quota` for the active account. It reports network failures and missing account/balance data instead of presenting cached data as refreshed. A connection change discards the old response.
- Explain that unused credits live in the same LISA account across reinstalls/devices, spent credits are not restored, and unfinished verified transactions reconcile automatically. No new credits are minted by refreshing.
- Present AI permission from one immutable `AISharingRequest`. Show named recipients, server host, message/history/memory/tool-result data, purpose, cancellation and withdrawal. Both sharing and age toggles start off; accepting rechecks the connection and consent generation before sending.
- Keep Cancel non-sending and preserve the draft. Keep existing recipient-change, withdrawal, retry and connection isolation guards.
