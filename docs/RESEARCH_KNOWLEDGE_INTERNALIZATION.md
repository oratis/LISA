> **本文档目标**：系统梳理**所有让知识从"外部/临时"变成"模型自身能力"的方案**——它们把知识放在哪、怎么写进去、能存多久、由什么决定该不该写。

## §1 什么叫"内化"——先把词定义清楚

日常说"模型学会了"混合了至少五种互不等价的性质。**分开它们，整个领域的地图才画得出来。**

### 1.1 内化的五个判据 💭

| 判据 | 含义 | 反例（有持久性但不满足） |
|---|---|---|
| **I1 免检索** | 无需显式查找步骤即可用 | RAG：检索不到就等于不存在 |
| **I2 组合性** | 能与其它知识组合，推出从未被明说的结论 | 记忆库条目：只能被原样召回 |
| **I3 隐式触发** | 不被点名也会在相关场合影响行为 | 关键词召回：不提就不触发 |
| **I4 跨会话持久** | 上下文清空后仍在 | 上下文窗口、KV 缓存、TTT 快权重 |
| **I5 抗干扰** | 不被上下文里的相反说法轻易覆盖 | 情境内学习：对上下文干扰不鲁棒（CoLLEGe ✅） |

> **"学会了" ≈ I1∧I2∧I3∧I4∧I5**。绝大多数现有方案只满足其中 2–3 条。
> **RAG 满足 I4，不满足 I1/I2/I3**——这是"知道有这回事"与"学会了"的差别。

### 1.2 ★ 内化度阶梯（本文档的主轴）💭

| 层级 | 载体 | I1 | I2 | I3 | I4 | I5 | 可逆性 | 可隔离性 |
|---|---|---|---|---|---|---|---|---|
| **L0** | 上下文窗口 / 提示 | ✓ | ◐ | ✓ | ✗ | ✗ | trivial | trivial |
| **L1** | 外部记忆 / RAG / agentic memory | ✗ | ✗ | ✗ | ✓ | ◐ | trivial（删条目） | trivial（命名空间） |
| **L2** | 激活 / 循环状态 / 快权重 | ✓ | ◐ | ✓ | ✗ | ◐ | 自动（易失） | 天然（每序列） |
| **L3** | 适配器 / PEFT / per-user LoRA | ✓ | ◐ | ✓ | ✓ | ✓ | 中（换/删模块） | **强**（一人一模块） |
| **L4** | 稀疏可寻址槽（product-key） | ✓ | ◐ | ✓ | ✓ | ✓ | 中（改槽） | **强**（key 空间分区） |
| **L5** | 稠密基座权重 | ✓ | ✓ | ✓ | ✓ | ✓ | **难** | **不可**（一套权重） |

> ### 🔑 核心张力：**内化度 ↑ ⟹ 可逆性 ↓、可隔离性 ↓**
> 越像"真学会"，就越难撤销、越容易与旧知识互相干扰、越难按人隔离。
> **所有工程方案本质上都是在这条对角线上选一个点。**
> 真正有意思的研究都在**中间层（L3/L4）**：让参数在持续写入下依然 durable 且可控。

### 1.3 内化流水线：六个环节 💭

任何方案都可拆成这六步，**各方案的差别在于覆盖了哪几步**：

```
① 获取 → ② 准入门控 → ③ 写入 → ④ 巩固 → ⑤ 保持/隔离 → ⑥ 调用
  acquire   gate         write    consolidate  retain/isolate  retrieve
```

> **实证发现（四轮调研）**：**环节 ② 是全领域最薄弱的一环。**
>
> 💭 **本项目的补充**：环节 ② 还应包含一个**元判断**——「**这条经验我判不判得了**」。
> 实测（[P0g](../research/learning-in-referencing/p0/README.md)）用 GT-free 的 `σ_null`（零分布离散度）做**可判定性闸门**，
> 把不可判定的转回环节 ①（继续追问获取），AUC **0.857 → 0.964**。
> **现有所有方案的门都是二态的（写/不写），没有"弃权"这一态。**
> 现有所有"该不该固化"的判据，其信号穷尽落在**十类代理**上（损失、参数漂移、容量/稀疏、表征或几何新颖、梯度干扰/多样性、代表性、随机/均匀、类别平衡、有标签下的不确定性、来源信誉/对源忠实/可靠/一致）——
> **"无 GT、无外部 oracle 的概念级正确性"一列为空**。详见 [§7.6.2 十类代理表](RESEARCH_LEARNING_IN_REFERENCING.md)。

## §2 三个正交轴

分类不该按"论文名"，该按机制。三个轴 + 一个横切维度：

### 轴 A｜内化到哪里（载体）
`上下文 → 外部存储 → 激活/状态 → 适配器 → 稀疏槽 → 稠密权重 → 新增架构模块`

### 轴 B｜用什么写入（写入算子）
| 算子 | 代表 | 特点 |
|---|---|---|
| **全局梯度下降** | 预训练、微调、持续学习 | 最彻底，也最易灾难性遗忘 |
| **测试期梯度** | TTT layers、Titans、TTT-NTP | 推理期原生写入，但**易失** |
| **闭式/局部规则** | delta 规则、Hebbian、ridge 闭式解 | 廉价、无全局耦合 |
| **直接权重编辑** | ROME、MEMIT、MEMOIR | 精准但顺序编辑会崩 |
| **文本写入** | RAG、MemGPT、agentic memory | 可逆、可审计、但不内化 |
| **权重合并** ⏳ | task arithmetic、TIES、model soup | 组合已有知识而非新增 |
| **蒸馏** ⏳ | context distillation、KD | **把"外部的"变成"内部的"** |
| **元学习生成** | CoLLEGe 概念嵌入生成器 | 即时产出可复用表征 |

### 轴 C｜何时写入（时机）
`预训练期 · 微调期 · 推理期（在线） · 离线巩固期（睡眠/idle）`

### 横切维度｜准入门控（决定该不该写）
**这是本项目的主战场**，也是全领域的空白（见 §1.3 与 §6）。

## §3 方案全景

> 每个家族回答四问：**内化到哪里 / 用什么写入 / 持久性 / 有无准入门控**。

### A. 情境内学习（ICL）— L0

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 上下文（激活层面，不进参数） |
| 写入算子 | 无（前向传播对参数只读） |
| 持久性 | **会话内，上下文一清即无** |
| 准入门控 | 无 |

- ✅ **主流理论是"任务定位"而非"习得"**：Xie et al.（ICLR 2022）ICL = 隐式贝叶斯推断，核心措辞是 *locating latent concepts*——在预训练已有的潜在概念中做后验定位。**数学上只覆盖分布内检索，不解释 OOD 新概念的获取。**
- ✅ **正典二分**：Pan et al.（ACL Findings 2023）task recognition（随机标签也 work）vs task learning（随规模涌现）。
- ✅ **但"真学习"有界**：von Oswald（ICML 2023）单层线性自注意力前向传播**可构造性等价于**一步梯度下降；❌ **但"真实 LLM 内部在跑 GD"的强版本 0-3 被否**。
- **根本限制**：不满足 I4/I5。CoLLEGe 逐字指出 *in-context prompting is not robust to context distractions*。

### B. 外部记忆 / RAG / Agentic Memory — L1

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 外部存储（文本/向量） |
| 写入算子 | 文本写入 |
| 持久性 | **跨会话 ✓** |
| 准入门控 | **有，且是 2026 热点** |

- 🔍 代表：MemGPT、生成式 agent、A-MEM。
- 🔍 **写入门控家族（离本项目最近的先例）**：**SAGE**（几何新颖度 s_vMF，ADD/UPDATE/NOOP 三元硬路由）、**Write-Time Gating**（来源信誉/provenance）、**TRUSTMEM**（对源忠实度）、**LOCI**（外部结果 oracle）。
- 🔍 **良性失败已很严重**：PersistBench 报告 18 个 LLM 的 **cross-domain 泄漏中位 53%**、sycophancy 97%。
- 🔍 **对抗面**：记忆投毒（MINJA 等，仅靠查询即可注入，成功率 >95%）；"越积极写/检索记忆的 agent 越易被投毒"。
- **根本限制**：**不满足 I1/I2/I3**——检索不到等于不存在，条目之间不组合。**这是"存储"不是"内化"。**

### C. 激活 / 循环状态 — L2

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 定长循环状态 / KV 缓存 |
| 写入算子 | 选择性状态更新（输入依赖门控） |
| 持久性 | **易失，序列结束即弃** |
| 准入门控 | 有门（Mamba 的选择性门），但只调**写入强度** |

- ⚠️ **容量墙未破**：Gated DeltaNet 原文——可精确存储的正交 KV 对数量**受模型维度界定**，超出即 *memory collisions*，信息 superimposed 且不可区分。
- ⚠️ 三篇 2026 后续（KATA、HOLA、Sparse Delta Memory）均确认容量墙未破（🔍 二手线索）。
- **重要区分** ✅：**状态叠加是激活级、每序列重置的易失干扰；MLP 叠加是参数级永久干扰。二者不可混谈。**
- 已 scale：Gated DeltaNet 已被 Qwen3-Next 采用（约 3:1 混合）🔍。

### D. 测试期训练 / 快权重 — L2（写参数但易失）

| 四问 | 答案 |
|---|---|
| 内化到哪里 | **权重级**（神经记忆模块 / MLP 知识权重） |
| 写入算子 | **测试期梯度**（原生推理期写入路径 ✓） |
| 持久性 | ❌ **易失——context 一撤即不留** |
| 准入门控 | 有（surprise / retention gate），但只调**覆盖强度** |

- ✅★ **全族易失，由自家作者认定**：Nested Learning（Google, NeurIPS 2025）p.25 高亮框逐字——
  > *"test-time training and test-time memorization are in fact instances of **parametric in-context learning**, where the acquired in-context knowledge **does not persist once the current context is removed**."*

  这是**对自身不利的承认**，证据等级最高。
- ✅ 逐个核实：TTT-NTP 每样本**显式回滚**；TTT-E2E *"reset after each prediction"*；Gated DeltaNet 序列结束即重置。
- 🚨 **命名陷阱**：**Titans 的 "persistent memory" 不是持久化通道**——它是"数据无关、测试期固定"的任务级参数（*"persistent memory parameters are fixed... should not be changed"*）。即 **"会写的不持久、叫持久的不写"**。已有二手博客误读，切勿沿用。
- ✅ **门控只调强度**：Titans 的 α_t（weight decay）、Miras 的 retention gate（Moneta/Yaad/Memora）。**Miras 四轴设计词典中没有任何一轴对应巩固或跨会话**（`consolidat`/`persist`/`cross-session` 全 0 命中）。

### E. 可寻址稀疏记忆 — L4 ★ 抗干扰的唯一定量证据

| 四问 | 答案 |
|---|---|
| 内化到哪里 | **1M 稀疏槽 product-key 记忆池**（参数） |
| 写入算子 | 反传训练循环（**非推理期**） |
| 持久性 | **✓ 参数即 checkpoint，天然跨会话** |
| 准入门控 | ◐ **TF-IDF 槽定位**（决定写哪些槽，不判知识对错） |

- ✅★ **Sparse Memory Finetuning**（FAIR at Meta）：新知识学习量相当时，旧能力跌幅 **full FT 89% / LoRA 71% / 稀疏记忆 11%**。
  - ⚠️ **四点方法学限定必须原样披露**：无表格（读自 Figure 3 曲线）、单次运行无误差棒、**优化器不对等**（稀疏用 SGD、基线用 AdamW）、**基线与实验架构不同**（dense 1.3B vs 记忆增强 1.3B）。
- ✅ **关键架构性质**：*"the keys and values are trainable **parameters** (rather than activations)"* → 与 TTT/Mamba 的易失状态形成对照。
- ✅ **Memory Layers at Scale**：1M 槽 product-key，做到 8B；但**测试期只读**，作者自陈需要"尚未发明的新学习方法"。
- 🎯 **一个现成的空实验**：稀疏槽已展示 1000 条 / 10,000 步不崩，vs ROME/MEMIT 的 10–40 次崩溃——**但从未有人做过同基准正面对比**（8 篇一手论文正文 `ROME`/`MEMIT` 命中 0 次）。

### F. 适配器 / per-user 模块 — L3 ★ 隔离的天然载体

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 低秩增量 ΔΘ_u（参数，base 冻结） |
| 写入算子 | 梯度（微调） |
| 持久性 | ✓ 跨会话 |
| 准入门控 | ❌ **无**（OPPU 无条件把用户全部历史固化） |

- ❌ **OPPU 的隔离零干扰断言 0-3 未过验证**（但机制上 base 冻结 + 互不相交的 ΔΘ_u 确实指向架构性隔离）。
- ✅ **作者级负证据**：OPPU 在 Limitations 中**自陈**"如何从用户历史中挑选最相关/最有价值的条目"与"如何处理不一致与冲突"是**未解决的未来工作**——**这正是缺少写入前准入判据的直接承认**。
- 🔍 生态：超网络从画像生成 PEFT、联邦 LoRA、PriME/PRISP。
- **本项目相关**：per-user LoRA 给了**隔离载体**，缺的正是**验证器**。

### G. 直接权重编辑 — L5

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 稠密 MLP 权重 |
| 写入算子 | **闭式 rank-one 编辑** |
| 持久性 | ✓ 永久 |
| 准入门控 | 无 |

- 🔍 **顺序编辑会崩**：ROME/MEND **10–20 次**即退化/collapse，MEMIT 约 **40 次**后仍稳（*Model Editing at Scale → Gradual and Catastrophic Forgetting*）。
- 🔍 MEMOIR（2025）最小覆写 + informed retention 缓解。
- **根本限制**：面向**已知 schema 的事实三元组**，不处理全新概念；**无隔离**（一套权重）；可逆性差。
- **根因**：知识在 MLP 中**叠加（superposition）**、不可寻址——碰一个必有涟漪。这正是 E 族（稀疏槽）要解决的问题。

### H. 模块化 / 可生长架构 — L3–L5

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 新增专家 / adapter / chart |
| 写入算子 | 梯度 + **架构增长** |
| 持久性 | ✓ |
| 准入门控 | **✓ 有真门控**（但信号非正确性） |

- ✅ **DEN**（ICLR 2018）：`if Lₜ > τ then DynamicExpansion`（**损失**）+ `‖Δwᵢ‖₂ > σ → 分裂`（**参数漂移**）。
- ✅ **SEMA**（CVPR 2025）：重构误差 **z 分数合取** > 阈值 → 扩容（**表征新颖性/分布漂移**）。⚠️ 措辞须写"z 分数归一化后的重构误差"。
- ✅ **HAT**（ICML 2018）：硬掩码由 SGD 学出，**无扩容判据**，task ID 由外部 oracle 给定。
- ✅ **CN-DPM**：DP 先验 × 似然 → WAKE/SLEEP **架构原生两段式**（门控在前、巩固在后）——**结构上最接近"推理期写入 + 带门控巩固"的耦合**。
- ❌ **StaR-MoE**：无条件"每任务加一专家"，**无门控**；且**共享路由器是干扰入口**（冻结旧专家不等于零干扰）。

### I. 局部学习规则 / 非反传 — L2–L4

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 联想记忆矩阵 / 局部突触 |
| 写入算子 | **局部规则**（Hebbian、delta、能量最小化） |
| 持久性 | 视载体而定 |
| 准入门控 | ◐ 部分有 |

- ⚠️ **Self-Sizing Hopfield v3**：**双阈值滞回控制律**（`ρₜ = ℓₜ/ℓ_prev > τ_hi 开 / < τ_lo 关`）——把结构性决策做成**架构原生控制律**。信号=归一化损失比 + 标签几何。
  - 🚨 **引用必须钉死 `arXiv:2507.10443v3`**：v1/v2 是完全不同的另一篇论文。单作者预印本，只作"机制先例"引。
- 🔍 **Recall-gated 巩固**（Lindsey & Litwin-Kumar, eLife 2024）：STM 召回重叠达阈 → 巩固该突触。**GT-free，但信号是熟悉度/可靠度 SNR，非概念真值。**
- 🔍 Forward-Forward、预测编码、平衡传播：**LLM 规模可行性无证据**，应作理论/玩具章节。
- **优势**：写一条不动其他（无全局梯度耦合）；**限制**：容量上界、超容量后崩溃形态未知。

## §4 横向对比矩阵（家族 × 缺失器官）

> ✓ 具备 · ◐ 部分 · ✗ 缺失。⏳ 家族待补。

| 家族 | 推理期写入 | 可寻址抗干扰 | 快/慢分离 | 巩固算子 | **准入门控** | **跨会话持久** | 可隔离 |

## §5 五个根本张力

### 5.1 稳定性—可塑性（stability-plasticity）
要学新东西就得改权重，改权重就毁旧知识。**规模上真的没解。** 所有方案都是缓解：replay、正则化、参数隔离、稀疏化。

### 5.2 叠加（superposition）→ 不可寻址
事实不在可定位的槽里，而散布在多义神经元上 → 改一个有涟漪 → 顺序编辑崩溃（ROME 10–20 次）。
**稀疏可寻址（E 族）是目前唯一有定量抗干扰证据的解法**（89%/71% → 11%）。

### 5.3 内化度 ↔ 可逆性/可隔离性 反比 💭
见 §1.2。**"永久"不该等于"不可逆"**——外部记忆删条目 trivial，权重里删除极难（机器遗忘/unlearning 是独立难题）。

### 5.4 容量上界
- 循环状态：正交 KV 对数 ≤ 模型维度，超出即碰撞 ⚠️
- 联想记忆：经典容量界
- 稀疏槽：上界与崩溃形态**完全未知**（1000 条未崩，10⁴？10⁵？）

### 5.5 隔离 vs 泛化
有些 per-user 学到的东西**应该**泛化给别人。"哪条该留在本地"本身是个判断问题，且**在架构文献中几乎未被提出**——
✅ 8 篇一手架构论文中 `user`/`users`/`speaker`/`interlocutor`/`per-user` **命中全为零**。

### 已验证的部分（[P0 实证](../research/learning-in-referencing/p0/README.md)）

### 与本文档其他家族的组合关系 💭

本项目的三层架构提案**不是新家族，而是把已有家族的器官拼起来 + 补上缺的门**：

```
L1 情景记忆  ← 借 D 族（TTT/Titans 推理期写入路径）+ E 族（product-key 稀疏槽）
⚙️ 巩固门     ← 【原创】σ_null 可判定性闸门 → 压缩增益 + 跨时间稳定 + EIG 收敛
                 三态：ACCEPT / REJECT / ASK（弃权转追问）
L2 巩固核    ← 借 E 族（低频稀疏记忆层）+ HOPE/CMS（频率分层）+ F 族（per-user 隔离）
```

**边界声明（必须写进论文）**：压缩增益验证的是**对该对话者用法的语义保真度**，不是**世界真值**——
它解决 **E1（模型误解 / gavagai）**，**不解决 E2（老师说假话）**；后者属 B 族的 provenance 门（Write-Time Gating / TRUSTMEM）射程，**两者正交可组合**。
