## §1 什么叫"内化"——先把词定义清楚

日常说"模型学会了"混合了至少五种互不等价的性质。**分开它们，整个领域的地图才画得出来。**

### 1.1 内化的五个判据 💭

| 判据 | 含义 | 反例（有持久性但不满足） |
|---|---|---|
| **I1 免检索** | 无需显式查找步骤即可用 | RAG：检索不到就等于不存在 |
| **I2 组合性** | 能与其它知识组合，推出从未被明说的结论 | 记忆库条目：只能被原样召回 |
| | 📌 **实测**：⊗ 世界知识 0.949（P6）· ⊗ 概念 0.889（P7）——**但都在同一个读出方向内**（见 §1.2 的 P8 注） | |
| **I3 隐式触发** | 不被点名也会在相关场合影响行为 | 关键词召回：不提就不触发 |
| **I4 跨会话持久** | 上下文清空后仍在 | 上下文窗口、KV 缓存、TTT 快权重 |
| **I5 抗干扰** | 不被上下文里的相反说法轻易覆盖 | 情境内学习：对上下文干扰不鲁棒（CoLLEGe ✅） |

> **"学会了" ≈ I1∧I2∧I3∧I4∧I5**。绝大多数现有方案只满足其中 2–3 条。
> **RAG 满足 I4，不满足 I1/I2/I3**——这是"知道有这回事"与"学会了"的差别。

### 1.2 ★ 内化度阶梯（本文档的主轴）💭

| 层级 | 载体 | I1 | I2 | I3 | I4 | I5 | 可逆性 | 可隔离性 |
|---|---|---|---|---|---|---|---|---|
| **L0** | 上下文窗口 / 提示 | ✓ | ◐ | ✓ | ✗ | ✗ | trivial | trivial |
| **L1** | 外部记忆 / RAG / agentic memory | ✗ | ✗ | ✗ | ✓ | ◐ | trivial（删条目） | trivial（命名空间） |
| **L2** | 激活 / 循环状态 / 快权重 | ✓ | ◐ | ✓ | ✗ | ◐ | 自动（易失） | 天然（每序列） |
| **L3** | 适配器 / PEFT / per-user LoRA | ✓ | ◐ | ✓ | ✓ | ✓ | 中（换/删模块） | **强**（一人一模块） |
| **L4** | 稀疏可寻址槽（product-key） | ✓ | ◐ | ✓ | ✓ | ✓ | 中（改槽） | **强**（key 空间分区） |
| **L5** | 稠密基座权重 | ✓ | ✓ | ✓ | ✓ | ✓ | **难** | **不可**（一套权重） |

> ### 📌 本表的 I2 列首次有了自家实证（[P6](../research/learning-in-referencing/p6/README.md)，2026-08-01）
> 同一批概念、同一批跨域探针（**概念 ⊗ 世界知识**，答案从未被明说）：
>
> | | 跨域 AUC |
> |---|---|
> | 无概念 base | **0.500** |
> | L0/L1 检索后注入上下文 | 0.840 |
> | **L4 稀疏槽（参数）** | **0.949** |
>
> **[P7](../research/learning-in-referencing/p7/README.md) 又补了「概念 ⊗ 概念」一格**（同一用户学两个概念、
> 探针问从未教过的合取句式，判据取两半的 min ⟹ 单概念策略在此为 0.500）：
> base **0.479** → L4 **0.889** → L1 上下文 **0.986**。
>
> ⟹ **L4 的 ◐ 对两种组合形态都成立**，但**低于上下文注入** —— 参数化路线在组合上确有代价。
> ⚠️ 两条限定：(a) 否定/量化/多跳/**同属性内的两个概念**仍未测，本表 I2 列其余部分仍是 💭 推演；
> (b) 表中 **L1 的 I2 = ✗ 指的是"条目只能被原样召回"**——一旦**检索后注入上下文**，
> 它就继承 L0 的 ◐（P6 的 0.840 正是这种混合形态），**不要拿 0.840 去反驳 L1 那一格**。

> ### 🔑 核心张力：**内化度 ↑ ⟹ 可逆性 ↓、可隔离性 ↓**
> 越像"真学会"，就越难撤销、越容易与旧知识互相干扰、越难按人隔离。
> **所有工程方案本质上都是在这条对角线上选一个点。**
>
> ### 🔴 [P8](../research/learning-in-referencing/p8/README.md) 给本表 **L4 行的 I3 = ✓ 加了一条硬前提**
> 本表的 L4 指的是**中间层** product-key 记忆。我方实际做的是 **final-layer** 版本
> （记忆挂在最后一层之后），它在 I3 上**实测不成立**：
> 换一个读出方向（Yes/No → A/B）后 AUC **0.507 ≈ base 0.500**，而上下文注入为 **1.000**。
>
> 机制已查清，且**否掉了"检索没取到"这个解释**（top-4 重合率 0.750）：
> `cos(m(h), W_yes−W_no) = +0.7926` vs `cos(m(h), W_A−W_B) = +0.0027`（两方向余弦 −0.0265），
> `‖m(h)‖ = 14.3` —— **不是太小，是方向不对**。
> 三种格式上，**迁移量随读出方向余弦单调**（1.000→0.960 · +0.107→0.755 · −0.027→0.555≈base）。
> 且**多格式训练不是解法**：加训第二种格式使其 +0.240，却让第三种（held-out）**−0.110**。
>
> ⟹ **本表 L4 的 I3 = ✓ 依赖于"记忆参与中间层表征计算"**。
> 只在输出层动手的变体，学到的是**读出方向**而非概念。
> ⚠️ 这同时说明**中间层版本是有实证动机的下一步**——但它**未做**，**不得声称已解决**。

> ### 🔑 P7 发现的**第二条张力（本表原先没有这一维）**：**可隔离性 ↑ ⟹ 组合性 ↓**
> 在 L4 上把每个**概念**也分区（写入与检索双掩码），能把顺序写入的退化压到 **0.000**，
> 但同一批探针上的**合取**从 **0.889 掉到 0.653**。
> 组合要求两个概念在**同一次检索里都被取到**，隔离要求它们**永不相见**——**两者要的正好相反**。
> ⟹ 「**顺序到达 + 强组合**」目前**无解**，是本表 L3/L4 那一段真正的空白。
> 真正有意思的研究都在**中间层（L3/L4）**：让参数在持续写入下依然 durable 且可控。

### 1.2b I1–I5 的可测化（💭→可操作定义，2026-08-01；每条给测量协议与判分）

> §8 待办「把判据做成可测指标」的兑现。以概念 c（如 gavagai 词）为被测单位；
> 全部协议零训练、可在冻结基座上跑；P1 生成器（`research/learning-in-referencing/p1/`）已能产出所需材料。

| 判据 | 可测指标 | 测量协议 | 判分 |
|---|---|---|---|
| **I1 免检索** | Δacc(无检索) | 移除记忆库/上下文中的 c 定义后，留出问句准确率 | acc 不掉 → I1=1；掉到基线 → I1=0 |
| **I2 组合性** | 未见组合泛化率 | 留出集限定为**教学中从未共现**的属性组合（P1 已保证）+ 两概念联合推理题（c₁∧c₂ 从未同句出现） | acc(未见组合) / acc(已见) ≥ 0.8 → I2=1 |
| **I3 隐式触发** | 不点名影响率 | 问句**不含**词 c 但语义相关（"Which of these would Tovi call ...?" → 换述为不出现 c 的分类任务） | 行为与 c 语义一致的比例 |
| **I4 跨会话持久** | 清空上下文后 acc | 新会话（无任何前缀）重测留出问句 | acc(新会话) / acc(原会话) |
| **I5 抗干扰** | 干扰鲁棒率 | 上下文注入相反定义（"actually {c} means {¬M}"）后重测 | 保持原判的比例；对照=ICL 基线（预期≈0） |

> 阶梯 L0–L5 的判级协议：对某载体逐条跑 I1–I5，得二值向量 → 对照 §1.2 表逐行匹配。
> **注意**：I2 的"◐"（部分组合性）判定用连续值（泛化率），不强行二值化。

任何方案都可拆成这六步，**各方案的差别在于覆盖了哪几步**：

```
① 获取 → ② 准入门控 → ③ 写入 → ④ 巩固 → ⑤ 保持/隔离 → ⑥ 调用
  acquire   gate         write    consolidate  retain/isolate  retrieve
```

> **实证发现（四轮调研）**：**环节 ② 是全领域最薄弱的一环。**
>
> 💭 **本项目的补充**：环节 ② 还应包含一个**元判断**——「**这条经验我判不判得了**」。
> 实测（[P0g](../research/learning-in-referencing/p0/README.md)）用 GT-free 的 `σ_null`（零分布离散度）做**可判定性闸门**，
> 把不可判定的转回环节 ①（继续追问获取），AUC **0.857 → 0.964**。
> **现有所有方案的门都是二态的（写/不写），没有"弃权"这一态。**
> 现有所有"该不该固化"的判据，其信号穷尽落在**十类代理**上（损失、参数漂移、容量/稀疏、表征或几何新颖、梯度干扰/多样性、代表性、随机/均匀、类别平衡、有标签下的不确定性、来源信誉/对源忠实/可靠/一致）——
> **"无 GT、无外部 oracle 的概念级正确性"一列为空**。详见 [§7.6.2 十类代理表](RESEARCH_LEARNING_IN_REFERENCING.md)。

## §2 三个正交轴

分类不该按"论文名"，该按机制。三个轴 + 一个横切维度：

### 轴 A｜内化到哪里（载体）
`上下文 → 外部存储 → 激活/状态 → 适配器 → 稀疏槽 → 稠密权重 → 新增架构模块`

### 轴 B｜用什么写入（写入算子）
| 算子 | 代表 | 特点 |
|---|---|---|
| **全局梯度下降** | 预训练、微调、持续学习 | 最彻底，也最易灾难性遗忘 |
| **测试期梯度** | TTT layers、Titans、TTT-NTP | 推理期原生写入，但**易失** |
| **闭式/局部规则** | delta 规则、Hebbian、ridge 闭式解 | 廉价、无全局耦合 |
| **直接权重编辑** | ROME、MEMIT、MEMOIR | 精准但顺序编辑会崩 |
| **文本写入** | RAG、MemGPT、agentic memory | 可逆、可审计、但不内化 |
| **权重合并** ⏳ | task arithmetic、TIES、model soup | 组合已有知识而非新增 |
| **蒸馏** ⏳ | context distillation、KD | **把"外部的"变成"内部的"** |
| **元学习生成** | CoLLEGe 概念嵌入生成器 | 即时产出可复用表征 |

### 轴 C｜何时写入（时机）
`预训练期 · 微调期 · 推理期（在线） · 离线巩固期（睡眠/idle）`

### 横切维度｜准入门控（决定该不该写）
**这是本项目的主战场**，也是全领域的空白（见 §1.3 与 §6）。

## §3 方案全景

> 每个家族回答四问：**内化到哪里 / 用什么写入 / 持久性 / 有无准入门控**。

### A. 情境内学习（ICL）— L0

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 上下文（激活层面，不进参数） |
| 写入算子 | 无（前向传播对参数只读） |
| 持久性 | **会话内，上下文一清即无** |
| 准入门控 | 无 |

- ✅ **主流理论是"任务定位"而非"习得"**：Xie et al.（ICLR 2022）ICL = 隐式贝叶斯推断，核心措辞是 *locating latent concepts*——在预训练已有的潜在概念中做后验定位。**数学上只覆盖分布内检索，不解释 OOD 新概念的获取。**
- ✅ **正典二分**：Pan et al.（ACL Findings 2023）task recognition（随机标签也 work）vs task learning（随规模涌现）。
- ✅ **但"真学习"有界**：von Oswald（ICML 2023）单层线性自注意力前向传播**可构造性等价于**一步梯度下降；❌ **但"真实 LLM 内部在跑 GD"的强版本 0-3 被否**。
- **根本限制**：不满足 I4/I5。CoLLEGe 逐字指出 *in-context prompting is not robust to context distractions*。

### B. 外部记忆 / RAG / Agentic Memory — L1

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 外部存储（文本/向量） |
| 写入算子 | 文本写入 |
| 持久性 | **跨会话 ✓** |
| 准入门控 | **有，且是 2026 热点** |

- 🔍 代表：MemGPT、生成式 agent、A-MEM。
- 🔍 **写入门控家族（离本项目最近的先例）**：**SAGE**（几何新颖度 s_vMF，ADD/UPDATE/NOOP 三元硬路由）、**Write-Time Gating**（来源信誉/provenance）、**TRUSTMEM**（对源忠实度）、**LOCI**（外部结果 oracle）。
- 🔍 **良性失败已很严重**：PersistBench 报告 18 个 LLM 的 **cross-domain 泄漏中位 53%**、sycophancy 97%。
- 🔍 **对抗面**：记忆投毒（MINJA 等，仅靠查询即可注入，成功率 >95%）；"越积极写/检索记忆的 agent 越易被投毒"。
- **根本限制**：**不满足 I1/I2/I3**——检索不到等于不存在，条目之间不组合。**这是"存储"不是"内化"。**

### C. 激活 / 循环状态 — L2

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 定长循环状态 / KV 缓存 |
| 写入算子 | 选择性状态更新（输入依赖门控） |
| 持久性 | **易失，序列结束即弃** |
| 准入门控 | 有门（Mamba 的选择性门），但只调**写入强度** |

- ⚠️ **容量墙未破**：Gated DeltaNet 原文——可精确存储的正交 KV 对数量**受模型维度界定**，超出即 *memory collisions*，信息 superimposed 且不可区分。
- ⚠️ 三篇 2026 后续（KATA、HOLA、Sparse Delta Memory）均确认容量墙未破（🔍 二手线索）。
- **重要区分** ✅：**状态叠加是激活级、每序列重置的易失干扰；MLP 叠加是参数级永久干扰。二者不可混谈。**
- 已 scale：Gated DeltaNet 已被 Qwen3-Next 采用（约 3:1 混合）🔍。

### D. 测试期训练 / 快权重 — L2（写参数但易失）

| 四问 | 答案 |
|---|---|
| 内化到哪里 | **权重级**（神经记忆模块 / MLP 知识权重） |
| 写入算子 | **测试期梯度**（原生推理期写入路径 ✓） |
| 持久性 | ❌ **易失——context 一撤即不留** |
| 准入门控 | 有（surprise / retention gate），但只调**覆盖强度** |

- ✅★ **全族易失，由自家作者认定**：Nested Learning（Google, NeurIPS 2025）p.25 高亮框逐字——
  > *"test-time training and test-time memorization are in fact instances of **parametric in-context learning**, where the acquired in-context knowledge **does not persist once the current context is removed**."*

  这是**对自身不利的承认**，证据等级最高。
- ✅ 逐个核实：TTT-NTP 每样本**显式回滚**；TTT-E2E *"reset after each prediction"*；Gated DeltaNet 序列结束即重置。
- 🚨 **命名陷阱**：**Titans 的 "persistent memory" 不是持久化通道**——它是"数据无关、测试期固定"的任务级参数（*"persistent memory parameters are fixed... should not be changed"*）。即 **"会写的不持久、叫持久的不写"**。已有二手博客误读，切勿沿用。
- ✅ **门控只调强度**：Titans 的 α_t（weight decay）、Miras 的 retention gate（Moneta/Yaad/Memora）。**Miras 四轴设计词典中没有任何一轴对应巩固或跨会话**（`consolidat`/`persist`/`cross-session` 全 0 命中）。

### E. 可寻址稀疏记忆 — L4 ★ 抗干扰的唯一定量证据

| 四问 | 答案 |
|---|---|

### J. 上下文蒸馏 / prompt internalization 🔍 ★ 最重要的一族

> **这就是"推理期获得的知识 → 永久内化"的那座桥。** 它的存在**修正了本文档 §4 原本的空白声明**（见下）。

| 四问 | 答案 |
|---|---|
| 内化到哪里 | **稠密权重**（Snell）/ **LoRA 适配器**（Prompt Distillation）/ **可训练 KV 前缀**（Cartridges）/ **加性 delta 权重**（Generative Adapter） |
| 写入算子 | **自蒸馏梯度**——让模型在**无该上下文**时复现自己有上下文时的输出 |
| 持久性 | **✓ 永久 / 跨会话** |
| 准入门控 | 🔴 **基本没有——凡进上下文即写。** ✅ 第九轮核实：2412.14964 **完全无筛**（噪声只靠软标签吸收）；OPCD 唯一的「filtered EKD」筛选**依赖带 GT 的 validation 打分 / 环境得分（非 GT-free）**，其 GT-free 设定自述 *"quality … not pre-evaluated"* 随机选取；Cartridges ✅ᶠ 无门；Snell ✅ 无门（第十轮 3–0） |

**谱系与关键结果**

| 工作 | 机制 | 关键数字 |
|---|---|---|
| ✅ **Learning by Distilling Context**（Snell et al. 2022，v1，第十轮 3 票）—— 术语锚点 | teacher = **同一模型的冻结副本**、条件化于详细指令+示例采样 y；student 在**最小 prompt**下学预测 **f(y)（剥掉 scratchpad 的最终答案）**；损失**实现为 token 级 KL**（teacher 软标签 100 采样近似），**非硬标签微调** | 蒸馏**输入无标签/合成、目标永远是 teacher 自身输出**（⚠️ 但标签间接进入：teacher prompt 内嵌带标签 in-context 示例、teacher 曾在带标签数据上微调）；**SPIDER 精确表述**：8-shot exact set match **27.9 vs 18.9，比直接梯度下降微调同 8 例高 9.0 点**（非对 teacher 28.2） |
| ✅ **Prompt Distillation**（Kujanpää et al. 2024-12，v2，第九轮 3 票） | teacher = **把文档塞进 prompt 的同一个模型**；student = 同一模型 + **LoRA**（rank 512–1024，翻转 adapter 切换角色）；**训练全程无 GT、无更强 teacher**（更大 expert 反因风格失配变差）；✅ **无任何数据准入筛选**——噪声答案不过滤，靠高温软标签蒸馏吸收 | 优于 SFT ✅；⚠️ **RAG 对比须限定**（第九轮收紧）：纯闭卷仅 Squadshifts/Llama-8B 追平；「超过」靠 **PD+RAG 组合**（三规模）或 **PD XL**（Squadshifts 均值）；**HotpotQA 上 RAG 对纯闭卷 PD 全面占优** |
| ✅ᶠ **Cartridges**（Eyuboglu et al. 2025-06）**已 scale** | 训练一个离线小 KV cache；**朴素 next-token 打不过 ICL，必须 self-study + 上下文蒸馏目标**。✅ᶠ **无门控**：Algorithm 1 是裸的 chunk→seed→sample 循环，**每条生成对话直接进训练集**，全文 2795 行穷举零命中；损失是纯 KL 上下文蒸馏，**无正确性/事实性/置信度项** | ✅ᶠ 38.6× 内存 / 26.4× 吞吐**数字准确**（逐字出现 3 次，基线=标准 ICL，1×H100/SGLang） |
| ✅ **OPCD**（Microsoft 2026-02，v2，第九轮 3 票） | on-policy + 上下文蒸馏合流：学生**无 context 采样自身轨迹**，对 context-conditioned 冻结 teacher 逐位置最小化 **reverse KL**（top-256 学生词表）；「filtered EKD」筛选**依赖 1000 道带 GT 的 math validation / 环境得分（非 GT-free）**，GT-free 的 test-time 设定**随机选取、自述 "not pre-evaluated"** | 含 **experiential knowledge distillation** 与 **system prompt distillation** ✅；⚠️「更好保留 OOD」**边际**（对 off-policy CD 仅 +0.1~+0.5、落在 std 内；对 base 持平或微降），且 **checkpoint 按 test accuracy 挑选**，数字受通胀 |
| 🔍 **Cartridges at Scale**（2026-06） | 修 Cartridges 的**不可组合**问题（朴素混合独立 cartridge → **性能坍缩到接近随机**） | 支持 **>100 万 token**；比 monolithic 高 10–31 点；比常规 RAG 少 **3–4×** prompt token |

**🔴 一个对本项目致命的失败模式**

✅ **When Context Returns**（2606.11627v1，第十轮 3 票）发现 **context-induced degradation**：
> 把原始 privileged context 在推理时**重新塞回**已蒸馏的 student，性能**反而变差**——**甚至在它无 context 时本已答对的样本上也退化**（Harm 指标）。

→ **内化不是幂等的。** 对"引用 → 内化"系统这是工程陷阱：**知识内化后，仍可能被同一份引用重新激活并劣化**。
修复：**NCA = stop-gradient 锚定 + forward KL 一致性正则（合为一项，β=0.5）**，每步仅多一次前向；**12 设定中 11 个降低 Harm**（唯一例外：FrozenLake 跨模型蒸馏反升）。
⚠️ **引用 scope（第十轮核定）**：退化**非普遍**——12 设定中 **7 个属退化域（Regime A）**，8 个 QA 设定全部出现非平凡 Harm；仅测**系统提示 + 游戏策略脚手架**（**未测文档/RAG context**）；单 seed、100 步全参微调、机制分析为单模型单游戏个案。

### K. 模型合并 / 任务向量 / 权重空间算术 🔍

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 稠密权重（delta / task vector 空间） |
| 写入算子 | **闭式权重加法**（无梯度、无需原始训练数据） |
| 持久性 | ✓ 永久（改的是 checkpoint 本身） |
| 准入门控 | 合并系数 λ + 稀疏化/符号选举等**启发式**，非语义信号 |

- 🔍 **Task Arithmetic**（Ilharco et al., ICLR 2023）：`τ = θ_ft − θ_pre`，支持加/减/类比。
  → ★ **取负（negation）提供了其他家族普遍缺失的可逆性**——这是 §5.3 的一个反例。
  → **硬边界**：所有 task vector 必须同祖同构；**只能组合"已被梯度训练出来的知识"，本身不能从推理期上下文产生新知识**。
- 🔍 **规模效应**（Yadav et al. / Google, 至 64B）：模型越大越易合并；合并 8 个大专家时，**在 held-out 未见任务上常优于多任务联合训练**。
- 🔴 **根本限制（2026 新证据）**：
  - 🔍 *Task-Level Model-Merging Collapse*（2026-03）：某些任务组合在**所有**合并方法下一致崩塌 → **崩塌是任务对的固有属性，不是方法缺陷**。归因反直觉：**表征不兼容**强相关，而参数空间冲突指标（方向/符号冲突、delta 重叠）**几乎不相关** → TIES/DARE 那类"消解参数干扰"的思路**诊断错了病因**。
  - 🔍 *Why Do More Experts Fail?*（2025）：用高斯宽度证明合并存在**解析上界**，新增专家边际收益**严格凹**并迅速饱和。**知识条数不是线性可加的。**
- 🔍 **DARE**（ICML 2024）：可丢弃 90–99% 的 delta 参数而能力几乎不损（SFT delta 值域极小、极度冗余）。**适用边界**：只对小幅 SFT delta 成立；继续预训练/强 RL 的大 delta 下失效。

### L. 知识蒸馏（teacher → student）🔍

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 稠密权重（少数变体到适配器） |
| 写入算子 | 梯度 |
| 持久性 | ✓ 永久 |
| 准入门控 | **教师分布**（off-policy 时为固定语料 → 无在线门控，这正是误差累积/暴露偏差的来源） |

- 🔍 **On-Policy Distillation**（Thinking Machines 2025-10）★：从**学生自己**采样轨迹 → 教师对**每 token** 打分（per-token 逆向 KL 作 advantage）→ policy gradient。
  **门控 = 教师 logprob，不需要 GT、不需要外部 reward，教师即验证器** ← 与 STaR（需 GT）的分水岭。
  - 数据：8B 学生 AIME'24 60%→70% 仅约 150 步；整体**少 7–10× 梯度步、低 50–100× 算力**。
  - ★★ **最相关的一条**：Qwen3-8B 在内部文档上 mid-train 后 IF-eval **85% → 45%**（混 70% chat 数据仍只有 79%，LoRA 也救不了）；再用**原模型自己当教师**做 on-policy 蒸馏，IF-eval 恢复到 **83%** 且知识分 **36%→41%**。
    → **"先写入新知识、再用自蒸馏修复被干扰的旧能力"是本族对"内化而不遗忘"最直接的工程答案。**
- 🔍 已 scale：Gemma 2、Qwen3 等技术报告已采用；2026-04 有专门综述把 OPD 形式化为 f-散度最小化。

### M. 检索增强 / 训练期检索内化 🔍 —— "何时该写进权重"的判据双轴

- 🔍 **经典锚点**：Ovadia et al.（EMNLP 2024）——非监督微调**学不进新事实**，RAG 稳定更优，**且 RAG 单用甚至优于 RAG+微调**；
  **但**：训练中暴露同一事实的**大量改写变体**可缓解。
- 🔍 **2026 翻转**：*Synthetic Mixed Training*（2026-03）用 **Focal Rewriting**（以问题为条件改写文档）把上条经验规模化 → QuaLITY 上**相对超过 RAG 4.4%**，与 RAG 结合 **+9.1%**，且随数据量/生成器强度**对数线性改进**。
  > **结论修正：不是"微调不行"，是"原文重复的微调不行"。需要以问题为条件的多样化改写**——这正是上下文蒸馏族的核心操作。
- 🔍 **判据双轴**（可直接用作写入决策）：
  - **规模轴**（*RAG-Considerate Pretraining* 标度律，2026-04，OLMo-2 30M–3B）：性能 = f(模型规模, 预训练 token, 检索库规模)；**非单调**，小模型从检索获益最大，大模型收益递减且出现**过度分配敏感性**。
  - **分布轴**（*Less Popular Knowledge*, 2024-03）：**实体越长尾，RAG 相对微调的优势越大**。
  > **合起来**：**高频 + 稳定 + 小模型 → 倾向写进权重；长尾 + 易变 + 大模型 → 倾向留在检索。**

### N. 自我改进 / 合成数据循环 🔍 —— 一条形式化的否定结论

- ✅ᶠ★ **Sharpening 机制**（Huang et al., ICLR 2025）：*sharpening* = 以模型自身作 verifier，把概率质量集中到高自奖励序列，
  本质是**把推理期计算摊销进权重**（原文：*amortizing the expensive inference-time computation*）。

  > ⚠️ **归因错误（第六轮改正）**：**"自我改进不可能创造新信息"不是本文证明的定理**，
  > 而是摘要第 2 句的**动机性前提**，正文 §1 明确归因于经典的 **data-processing inequality（Cover, 1999）**。
  > 本文自证的定理是 SFT-/RLHF-Sharpening 的**样本复杂度与 minimax 最优性**，是另一个命题。
  > **⟹ 引用时应引 data-processing inequality，不可写成"本文证明了…"。**

  > ✅ᶠ **但适用范围的核查对我方有利**：论文**显式限定在"无外部反馈"的自采样设定**
  > （摘要把 self-improvement 定义为 *without external feedback*；§1.1 规定 self-reward 纯由 base model 导出，无外部监督）。
  > **⟹ 该结论不能外推到"有外部证据进入上下文"的情形，因此我方推论成立**：
  > 凡"写入源 = 模型自采样"的家族受 coverage 约束；**真正的新知识必须来自外部证据** —— 反向确认**上下文蒸馏（J）才是那座桥**。
- 🔍 **STaR**（2022）：门控 = **最终答案正确性 → 需要 GT**。与 on-policy 蒸馏（教师即验证器，无需 GT）和本项目（无 GT 自验证）形成三方对照。
- 🔴 **模型坍缩，及其边界条件**：
  - 🔍 Shumailov et al.（**Nature 2024**）：递归训练自身输出 → **尾部消失、不可逆缺陷**。
  - ⚠️ **但** Gerstgrasser et al.（2024）修正：既往研究默认新数据**替换**旧数据；改为**累积**则**坍缩消失**，测试误差有**与迭代次数无关的有限上界**。
  > **坍缩不是"合成数据"的固有属性，而是"替换式自消费 + 无门控"的属性。**
  > 引用 Nature 那条时**必须连同边界条件一起标注**，否则会把过强结论写进文档。

### O. 睡眠期 / 离线计算 🔍

- ✅ **Sleep-time Compute**（Letta + UC Berkeley, 2025-04）——**该族源头并不写权重**（第七轮 3 票验证）。
  机制：拆 prompt 为静态 context + 动态 query，空闲期只对 context 做推理/摘要，产出 `S(c) → c′`，测试期 `T_b(q, c′) → a`。
  内化到 → **外部自然语言文本工件**；持久性 → 跨会话但可删可覆盖（**可逆**）。
  效果 ✅：token 降约 **5×**；Stateful GSM-Symbolic **+13%**、Stateful AIME **+18%**（逐字核实）。

  ✅ **不写权重的证据（LaTeX 源码级）**：`weight`=0、`gradient`=0、`backprop`=0、`parametric`=0、`adapter`=0、`LoRA`=0、`checkpoint`=0、`SGD`=0；

  ✅ **无正确性门控**：全文（pdftotext 11,988 词 + HTML + e-print 三重抽取）零命中 admission/gate/criterion/threshold/verification/factual/trust/confidence/reliability/novelty/surprise/salience/discard。

- ✅★ **Language Models Need Sleep**（Behrouz et al., 2026-06 v1 / 07-10 v2，**Titans/HOPE 同一组**）：把睡眠期**正式做成知识内化机制**。

### P. 参数化知识库 / 神经数据库 🔍

- ✅ᶠ★ **LMLM**（Weinberger 组）——**机制最干净：在训练期就决定"不内化"**。
  做法：预训练时把检索到的**事实值从训练损失中 mask 掉**（逐 token：`m_t = 0` 当 `x_t ∈ {retrieved values, <|db_end|>}`，Eq.1），教模型学会"发起定向查表"而非把长尾事实压进权重。
  ✅ᶠ **有效性消融**：推理期禁用数据库后事实精度大幅塌陷（FactScore **31.9 → 12.8**，T-REx EM **58.1 → 38.5**）——证明该知识确实不在权重里。
  结果：以远小的规模取得可比表现，同时获得**显式、可编辑、可验证的知识库**，支持 **instant forgetting**。
  → **直击可逆性与隔离性**：知识写在人类可读 KB 里，删除=删行。续作 Co-LMLM（2026-07）放宽模板约束。

## §5 五个根本张力

### 5.1 稳定性—可塑性（stability-plasticity）
要学新东西就得改权重，改权重就毁旧知识。**规模上真的没解。** 所有方案都是缓解：replay、正则化、参数隔离、稀疏化。

### 5.2 叠加（superposition）→ 不可寻址
事实不在可定位的槽里，而散布在多义神经元上 → 改一个有涟漪 → 顺序编辑崩溃（ROME 10–20 次）。
**稀疏可寻址（E 族）是目前唯一有定量抗干扰证据的解法**（89%/71% → 11%）。

### 5.3 内化度 ↔ 可逆性/可隔离性 反比 💭
见 §1.2。**"永久"不该等于"不可逆"**——外部记忆删条目 trivial，权重里删除极难（机器遗忘/unlearning 是独立难题）。

**机器遗忘文献（🔍 全部未经本项目验证，引用前须逐条核实；2026-08-01 补）**：

| 工作 | 要点（对本表的意义） |
|---|---|
| 🔍 SISA（Bourtoule et al., IEEE S&P 2021） | **分片重训**：把"可逆性"做成训练时的架构承诺（数据分片 → 删数据只重训对应分片）——与 L4 稀疏槽"改槽即忘"同构，佐证「可逆性要在写入前设计，事后补救极贵」 |
| 🔍 Who's Harry Potter（Eldan & Russinovich, 2310.02238） | 稠密权重上的目标遗忘（L5）：可行但成本高、有旁损——L5 可逆性差的实例 |
| 🔍 TOFU（Maini et al., 2401.06121） | 遗忘评测基准：**"删干净"本身难以判定**——本项目 P4 隔离测试的"冲突词泄漏"判分应借其思路（行为级+概率级双判） |
| 🔍 RMU（Li et al., 2403.03218） | 表征扰动式遗忘：作用在激活层——说明"忘"也有 L2–L5 的层级选择 |
| ✅ Task-vector 取负（Ilharco, ICLR 2023，§K 已核） | 闭式权重减法可逆——K 族已验证的反例，本表锚点 |

> 对本项目的直接含义：**巩固门的 DEFER→evict 路径（未毕业即淘汰）是"写入前可逆性"**，
> 比任何 unlearning 都便宜——这正是三态门 + L1 缓冲设计的一个卖点，论文 §Design 可点一句。

### 5.4 容量上界
- 循环状态：正交 KV 对数 ≤ 模型维度，超出即碰撞 ⚠️
- 联想记忆：经典容量界
- 稀疏槽：上界与崩溃形态**完全未知**（1000 条未崩，10⁴？10⁵？）

### 5.5 隔离 vs 泛化
有些 per-user 学到的东西**应该**泛化给别人。"哪条该留在本地"本身是个判断问题，且**在架构文献中几乎未被提出**——
✅ 8 篇一手架构论文中 `user`/`users`/`speaker`/`interlocutor`/`per-user` **命中全为零**。

凡"写入源 = 模型自采样"的家族都受 coverage 约束，只能锐化已有能力。

> → 这从理论侧**确认了本项目的问题设定是对的**：新概念必须**在引用中从对话者那里获得**，而不可能靠模型自己想出来。

### 已验证的部分（[P0 实证](../research/learning-in-referencing/p0/README.md)）

| 结论 | 数据 |
|---|---|
| **压缩增益能分开"真意 M"与"误解 M′"** | 22 items，margin **+4.08 nats** 95%CI[+2.52,+5.70]，**19/22, p=0.00043** |

| 🔴 **作用域受概念类型限制** | G2 范畴/G3 材料 **AUC 1.000** ≫ G1 合取 0.861 ≫ **G4 论元顺序 0.562 ≈ 随机**（已归因为基座能力边界） |

### 与本文档其他家族的组合关系 💭

本项目的三层架构提案**不是新家族，而是把已有家族的器官拼起来 + 补上缺的门**：

```
L1 情景记忆  ← 借 D 族（TTT/Titans 推理期写入路径）+ E 族（product-key 稀疏槽）
⚙️ 巩固门     ← 【原创】σ_null 可判定性闸门 → 压缩增益 + 跨时间稳定 + EIG 收敛
                 三态：ACCEPT / REJECT / ASK（弃权转追问）
L2 巩固核    ← 借 E 族（低频稀疏记忆层）+ HOPE/CMS（频率分层）+ F 族（per-user 隔离）
```

**边界声明（必须写进论文）**：压缩增益验证的是**对该对话者用法的语义保真度**，不是**世界真值**——
它解决 **E1（模型误解 / gavagai）**，**不解决 E2（老师说假话）**；后者属 B 族的 provenance 门（Write-Time Gating / TRUSTMEM）射程，**两者正交可组合**。
