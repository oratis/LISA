## §1 什么叫"内化"——先把词定义清楚

日常说"模型学会了"混合了至少五种互不等价的性质。**分开它们，整个领域的地图才画得出来。**

### 1.1 内化的五个判据 💭

| 判据 | 含义 | 反例（有持久性但不满足） |
|---|---|---|
| **I1 免检索** | 无需显式查找步骤即可用 | RAG：检索不到就等于不存在 |
| **I2 组合性** | 能与其它知识组合，推出从未被明说的结论 | 记忆库条目：只能被原样召回 |
| **I3 隐式触发** | 不被点名也会在相关场合影响行为 | 关键词召回：不提就不触发 |
| **I4 跨会话持久** | 上下文清空后仍在 | 上下文窗口、KV 缓存、TTT 快权重 |
| **I5 抗干扰** | 不被上下文里的相反说法轻易覆盖 | 情境内学习：对上下文干扰不鲁棒（CoLLEGe ✅） |

> **"学会了" ≈ I1∧I2∧I3∧I4∧I5**。绝大多数现有方案只满足其中 2–3 条。
> **RAG 满足 I4，不满足 I1/I2/I3**——这是"知道有这回事"与"学会了"的差别。

### 1.2 ★ 内化度阶梯（本文档的主轴）💭

| 层级 | 载体 | I1 | I2 | I3 | I4 | I5 | 可逆性 | 可隔离性 |
|---|---|---|---|---|---|---|---|---|
| **L0** | 上下文窗口 / 提示 | ✓ | ◐ | ✓ | ✗ | ✗ | trivial | trivial |
| **L1** | 外部记忆 / RAG / agentic memory | ✗ | ✗ | ✗ | ✓ | ◐ | trivial（删条目） | trivial（命名空间） |
| **L2** | 激活 / 循环状态 / 快权重 | ✓ | ◐ | ✓ | ✗ | ◐ | 自动（易失） | 天然（每序列） |
| **L3** | 适配器 / PEFT / per-user LoRA | ✓ | ◐ | ✓ | ✓ | ✓ | 中（换/删模块） | **强**（一人一模块） |
| **L4** | 稀疏可寻址槽（product-key） | ✓ | ◐ | ✓ | ✓ | ✓ | 中（改槽） | **强**（key 空间分区） |
| **L5** | 稠密基座权重 | ✓ | ✓ | ✓ | ✓ | ✓ | **难** | **不可**（一套权重） |

> ### 🔑 核心张力：**内化度 ↑ ⟹ 可逆性 ↓、可隔离性 ↓**
> 越像"真学会"，就越难撤销、越容易与旧知识互相干扰、越难按人隔离。
> **所有工程方案本质上都是在这条对角线上选一个点。**
> 真正有意思的研究都在**中间层（L3/L4）**：让参数在持续写入下依然 durable 且可控。

### 1.3 内化流水线：六个环节 💭

任何方案都可拆成这六步，**各方案的差别在于覆盖了哪几步**：

```
① 获取 → ② 准入门控 → ③ 写入 → ④ 巩固 → ⑤ 保持/隔离 → ⑥ 调用
  acquire   gate         write    consolidate  retain/isolate  retrieve
```

> **实证发现（四轮调研）**：**环节 ② 是全领域最薄弱的一环。**
>
> 💭 **本项目的补充**：环节 ② 还应包含一个**元判断**——「**这条经验我判不判得了**」。
> 实测（[P0g](../research/learning-in-referencing/p0/README.md)）用 GT-free 的 `σ_null`（零分布离散度）做**可判定性闸门**，
> 把不可判定的转回环节 ①（继续追问获取），AUC **0.857 → 0.964**。
> **现有所有方案的门都是二态的（写/不写），没有"弃权"这一态。**
> 现有所有"该不该固化"的判据，其信号穷尽落在**十类代理**上（损失、参数漂移、容量/稀疏、表征或几何新颖、梯度干扰/多样性、代表性、随机/均匀、类别平衡、有标签下的不确定性、来源信誉/对源忠实/可靠/一致）——
> **"无 GT、无外部 oracle 的概念级正确性"一列为空**。详见 [§7.6.2 十类代理表](RESEARCH_LEARNING_IN_REFERENCING.md)。

## §2 三个正交轴

分类不该按"论文名"，该按机制。三个轴 + 一个横切维度：

### 轴 A｜内化到哪里（载体）
`上下文 → 外部存储 → 激活/状态 → 适配器 → 稀疏槽 → 稠密权重 → 新增架构模块`

### 轴 B｜用什么写入（写入算子）
| 算子 | 代表 | 特点 |
|---|---|---|
| **全局梯度下降** | 预训练、微调、持续学习 | 最彻底，也最易灾难性遗忘 |
| **测试期梯度** | TTT layers、Titans、TTT-NTP | 推理期原生写入，但**易失** |
| **闭式/局部规则** | delta 规则、Hebbian、ridge 闭式解 | 廉价、无全局耦合 |
| **直接权重编辑** | ROME、MEMIT、MEMOIR | 精准但顺序编辑会崩 |
| **文本写入** | RAG、MemGPT、agentic memory | 可逆、可审计、但不内化 |
| **权重合并** ⏳ | task arithmetic、TIES、model soup | 组合已有知识而非新增 |
| **蒸馏** ⏳ | context distillation、KD | **把"外部的"变成"内部的"** |
| **元学习生成** | CoLLEGe 概念嵌入生成器 | 即时产出可复用表征 |

### 轴 C｜何时写入（时机）
`预训练期 · 微调期 · 推理期（在线） · 离线巩固期（睡眠/idle）`

### 横切维度｜准入门控（决定该不该写）
**这是本项目的主战场**，也是全领域的空白（见 §1.3 与 §6）。

## §3 方案全景

> 每个家族回答四问：**内化到哪里 / 用什么写入 / 持久性 / 有无准入门控**。

### A. 情境内学习（ICL）— L0

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 上下文（激活层面，不进参数） |
| 写入算子 | 无（前向传播对参数只读） |
| 持久性 | **会话内，上下文一清即无** |
| 准入门控 | 无 |

- ✅ **主流理论是"任务定位"而非"习得"**：Xie et al.（ICLR 2022）ICL = 隐式贝叶斯推断，核心措辞是 *locating latent concepts*——在预训练已有的潜在概念中做后验定位。**数学上只覆盖分布内检索，不解释 OOD 新概念的获取。**
- ✅ **正典二分**：Pan et al.（ACL Findings 2023）task recognition（随机标签也 work）vs task learning（随规模涌现）。
- ✅ **但"真学习"有界**：von Oswald（ICML 2023）单层线性自注意力前向传播**可构造性等价于**一步梯度下降；❌ **但"真实 LLM 内部在跑 GD"的强版本 0-3 被否**。
- **根本限制**：不满足 I4/I5。CoLLEGe 逐字指出 *in-context prompting is not robust to context distractions*。

### B. 外部记忆 / RAG / Agentic Memory — L1

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 外部存储（文本/向量） |
| 写入算子 | 文本写入 |
| 持久性 | **跨会话 ✓** |
| 准入门控 | **有，且是 2026 热点** |

- 🔍 代表：MemGPT、生成式 agent、A-MEM。
- 🔍 **写入门控家族（离本项目最近的先例）**：**SAGE**（几何新颖度 s_vMF，ADD/UPDATE/NOOP 三元硬路由）、**Write-Time Gating**（来源信誉/provenance）、**TRUSTMEM**（对源忠实度）、**LOCI**（外部结果 oracle）。
- 🔍 **良性失败已很严重**：PersistBench 报告 18 个 LLM 的 **cross-domain 泄漏中位 53%**、sycophancy 97%。
- 🔍 **对抗面**：记忆投毒（MINJA 等，仅靠查询即可注入，成功率 >95%）；"越积极写/检索记忆的 agent 越易被投毒"。
- **根本限制**：**不满足 I1/I2/I3**——检索不到等于不存在，条目之间不组合。**这是"存储"不是"内化"。**

### C. 激活 / 循环状态 — L2

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 定长循环状态 / KV 缓存 |
| 写入算子 | 选择性状态更新（输入依赖门控） |
| 持久性 | **易失，序列结束即弃** |
| 准入门控 | 有门（Mamba 的选择性门），但只调**写入强度** |

- ⚠️ **容量墙未破**：Gated DeltaNet 原文——可精确存储的正交 KV 对数量**受模型维度界定**，超出即 *memory collisions*，信息 superimposed 且不可区分。
- ⚠️ 三篇 2026 后续（KATA、HOLA、Sparse Delta Memory）均确认容量墙未破（🔍 二手线索）。
- **重要区分** ✅：**状态叠加是激活级、每序列重置的易失干扰；MLP 叠加是参数级永久干扰。二者不可混谈。**
- 已 scale：Gated DeltaNet 已被 Qwen3-Next 采用（约 3:1 混合）🔍。

### D. 测试期训练 / 快权重 — L2（写参数但易失）

| 四问 | 答案 |
|---|---|
| 内化到哪里 | **权重级**（神经记忆模块 / MLP 知识权重） |
| 写入算子 | **测试期梯度**（原生推理期写入路径 ✓） |
| 持久性 | ❌ **易失——context 一撤即不留** |
| 准入门控 | 有（surprise / retention gate），但只调**覆盖强度** |

- ✅★ **全族易失，由自家作者认定**：Nested Learning（Google, NeurIPS 2025）p.25 高亮框逐字——
  > *"test-time training and test-time memorization are in fact instances of **parametric in-context learning**, where the acquired in-context knowledge **does not persist once the current context is removed**."*

  这是**对自身不利的承认**，证据等级最高。
- ✅ 逐个核实：TTT-NTP 每样本**显式回滚**；TTT-E2E *"reset after each prediction"*；Gated DeltaNet 序列结束即重置。
- 🚨 **命名陷阱**：**Titans 的 "persistent memory" 不是持久化通道**——它是"数据无关、测试期固定"的任务级参数（*"persistent memory parameters are fixed... should not be changed"*）。即 **"会写的不持久、叫持久的不写"**。已有二手博客误读，切勿沿用。
- ✅ **门控只调强度**：Titans 的 α_t（weight decay）、Miras 的 retention gate（Moneta/Yaad/Memora）。**Miras 四轴设计词典中没有任何一轴对应巩固或跨会话**（`consolidat`/`persist`/`cross-session` 全 0 命中）。

### E. 可寻址稀疏记忆 — L4 ★ 抗干扰的唯一定量证据

| 四问 | 答案 |
|---|---|
| 内化到哪里 | **1M 稀疏槽 product-key 记忆池**（参数） |
| 写入算子 | 反传训练循环（**非推理期**） |
| 持久性 | **✓ 参数即 checkpoint，天然跨会话** |
| 准入门控 | ◐ **TF-IDF 槽定位**（决定写哪些槽，不判知识对错） |

- ✅★ **Sparse Memory Finetuning**（FAIR at Meta）：新知识学习量相当时，旧能力跌幅 **full FT 89% / LoRA 71% / 稀疏记忆 11%**。
  - ⚠️ **四点方法学限定必须原样披露**：无表格（读自 Figure 3 曲线）、单次运行无误差棒、**优化器不对等**（稀疏用 SGD、基线用 AdamW）、**基线与实验架构不同**（dense 1.3B vs 记忆增强 1.3B）。
- ✅ **关键架构性质**：*"the keys and values are trainable **parameters** (rather than activations)"* → 与 TTT/Mamba 的易失状态形成对照。
- ✅ **Memory Layers at Scale**：1M 槽 product-key，做到 8B；但**测试期只读**，作者自陈需要"尚未发明的新学习方法"。
- 🎯 **一个现成的空实验**：稀疏槽已展示 1000 条 / 10,000 步不崩，vs ROME/MEMIT 的 10–40 次崩溃——**但从未有人做过同基准正面对比**（8 篇一手论文正文 `ROME`/`MEMIT` 命中 0 次）。

### F. 适配器 / per-user 模块 — L3 ★ 隔离的天然载体

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 低秩增量 ΔΘ_u（参数，base 冻结） |
| 写入算子 | 梯度（微调） |
| 持久性 | ✓ 跨会话 |
| 准入门控 | ❌ **无**（OPPU 无条件把用户全部历史固化） |

- ❌ **OPPU 的隔离零干扰断言 0-3 未过验证**（但机制上 base 冻结 + 互不相交的 ΔΘ_u 确实指向架构性隔离）。
- ✅ **作者级负证据**：OPPU 在 Limitations 中**自陈**"如何从用户历史中挑选最相关/最有价值的条目"与"如何处理不一致与冲突"是**未解决的未来工作**——**这正是缺少写入前准入判据的直接承认**。
- 🔍 生态：超网络从画像生成 PEFT、联邦 LoRA、PriME/PRISP。
- **本项目相关**：per-user LoRA 给了**隔离载体**，缺的正是**验证器**。

### G. 直接权重编辑 — L5

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 稠密 MLP 权重 |
| 写入算子 | **闭式 rank-one 编辑** |
| 持久性 | ✓ 永久 |
| 准入门控 | 无 |

- 🔍 **顺序编辑会崩**：ROME/MEND **10–20 次**即退化/collapse，MEMIT 约 **40 次**后仍稳（*Model Editing at Scale → Gradual and Catastrophic Forgetting*）。
- 🔍 MEMOIR（2025）最小覆写 + informed retention 缓解。
- **根本限制**：面向**已知 schema 的事实三元组**，不处理全新概念；**无隔离**（一套权重）；可逆性差。
- **根因**：知识在 MLP 中**叠加（superposition）**、不可寻址——碰一个必有涟漪。这正是 E 族（稀疏槽）要解决的问题。

### H. 模块化 / 可生长架构 — L3–L5

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 新增专家 / adapter / chart |
| 写入算子 | 梯度 + **架构增长** |
| 持久性 | ✓ |
| 准入门控 | **✓ 有真门控**（但信号非正确性） |

- ✅ **DEN**（ICLR 2018）：`if Lₜ > τ then DynamicExpansion`（**损失**）+ `‖Δwᵢ‖₂ > σ → 分裂`（**参数漂移**）。
- ✅ **SEMA**（CVPR 2025）：重构误差 **z 分数合取** > 阈值 → 扩容（**表征新颖性/分布漂移**）。⚠️ 措辞须写"z 分数归一化后的重构误差"。
- ✅ **HAT**（ICML 2018）：硬掩码由 SGD 学出，**无扩容判据**，task ID 由外部 oracle 给定。
- ✅ **CN-DPM**：DP 先验 × 似然 → WAKE/SLEEP **架构原生两段式**（门控在前、巩固在后）——**结构上最接近"推理期写入 + 带门控巩固"的耦合**。
- ❌ **StaR-MoE**：无条件"每任务加一专家"，**无门控**；且**共享路由器是干扰入口**（冻结旧专家不等于零干扰）。

### I. 局部学习规则 / 非反传 — L2–L4

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 联想记忆矩阵 / 局部突触 |
| 写入算子 | **局部规则**（Hebbian、delta、能量最小化） |
| 持久性 | 视载体而定 |
| 准入门控 | ◐ 部分有 |

- ⚠️ **Self-Sizing Hopfield v3**：**双阈值滞回控制律**（`ρₜ = ℓₜ/ℓ_prev > τ_hi 开 / < τ_lo 关`）——把结构性决策做成**架构原生控制律**。信号=归一化损失比 + 标签几何。
  - 🚨 **引用必须钉死 `arXiv:2507.10443v3`**：v1/v2 是完全不同的另一篇论文。单作者预印本，只作"机制先例"引。
- 🔍 **Recall-gated 巩固**（Lindsey & Litwin-Kumar, eLife 2024）：STM 召回重叠达阈 → 巩固该突触。**GT-free，但信号是熟悉度/可靠度 SNR，非概念真值。**
- 🔍 Forward-Forward、预测编码、平衡传播：**LLM 规模可行性无证据**，应作理论/玩具章节。
- **优势**：写一条不动其他（无全局梯度耦合）；**限制**：容量上界、超容量后崩溃形态未知。

### J. 上下文蒸馏 / prompt internalization 🔍 ★ 最重要的一族

> **这就是"推理期获得的知识 → 永久内化"的那座桥。** 它的存在**修正了本文档 §4 原本的空白声明**（见下）。

| 四问 | 答案 |
|---|---|
| 内化到哪里 | **稠密权重**（Snell）/ **LoRA 适配器**（Prompt Distillation）/ **可训练 KV 前缀**（Cartridges）/ **加性 delta 权重**（Generative Adapter） |
| 写入算子 | **自蒸馏梯度**——让模型在**无该上下文**时复现自己有上下文时的输出 |
| 持久性 | **✓ 永久 / 跨会话** |
| 准入门控 | 🔴 **整族没有。凡进上下文即写。** |

**谱系与关键结果**

| 工作 | 机制 | 关键数字 |
|---|---|---|
| 🔍 **Learning by Distilling Context**（Snell et al. 2022）—— 术语锚点 | 先在 `[instructions]+[input]` 条件下生成，再微调模型在**无 instructions** 下直接预测自己刚才的答案 | 用 **unlabeled** 合成输入，**不需要 GT** ← 与本项目性质一致；SPIDER 上比梯度下降高 9% |
| 🔍 **Prompt Distillation**（Kujanpää et al. 2024-12） | teacher = **把文档塞进 prompt 的同一个模型**；student 学无文档时复现其回答，落在 **LoRA** 上 | **不需要 GT、不需要更强 teacher**；优于 SFT，**多个规模上超过 RAG** |
| 🔍 **Cartridges**（Eyuboglu et al. 2025-06）**已 scale** | 训练一个离线小 KV cache；**朴素 next-token 打不过 ICL，必须 self-study + 上下文蒸馏目标** | 匹配 ICL 同时省 **38.6× 内存、吞吐 26.4×**；MTOB 有效上下文 128k→484k |
| 🔍 **OPCD**（Microsoft 2026-02） | on-policy + 上下文蒸馏合流：学生在自己轨迹上对 context-conditioned teacher 最小化 reverse KL | 含 **experiential knowledge distillation**（从自身历史轨迹固化知识）与 **system prompt distillation**；更好保留 OOD |
| 🔍 **Cartridges at Scale**（2026-06） | 修 Cartridges 的**不可组合**问题（朴素混合独立 cartridge → **性能坍缩到接近随机**） | 支持 **>100 万 token**；比 monolithic 高 10–31 点；比常规 RAG 少 **3–4×** prompt token |

**🔴 一个对本项目致命的失败模式**

🔍 **When Context Returns**（2026-06）发现 **context-induced degradation**：
> 把原始 privileged context 在推理时**重新塞回**已蒸馏的 student，性能**反而变差**——**甚至在它无 context 时本已答对的样本上也退化**。

→ **内化不是幂等的。** 对"引用 → 内化"系统这是工程陷阱：**知识内化后，仍可能被同一份引用重新激活并劣化**。
修复：`stop-gradient anchoring + forward KL 一致性正则`（保证 *context removability*），每步仅多一次前向；12 种配置中 11 种有效。

### K. 模型合并 / 任务向量 / 权重空间算术 🔍

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 稠密权重（delta / task vector 空间） |
| 写入算子 | **闭式权重加法**（无梯度、无需原始训练数据） |
| 持久性 | ✓ 永久（改的是 checkpoint 本身） |
| 准入门控 | 合并系数 λ + 稀疏化/符号选举等**启发式**，非语义信号 |

- 🔍 **Task Arithmetic**（Ilharco et al., ICLR 2023）：`τ = θ_ft − θ_pre`，支持加/减/类比。
  → ★ **取负（negation）提供了其他家族普遍缺失的可逆性**——这是 §5.3 的一个反例。
  → **硬边界**：所有 task vector 必须同祖同构；**只能组合"已被梯度训练出来的知识"，本身不能从推理期上下文产生新知识**。
- 🔍 **规模效应**（Yadav et al. / Google, 至 64B）：模型越大越易合并；合并 8 个大专家时，**在 held-out 未见任务上常优于多任务联合训练**。
- 🔴 **根本限制（2026 新证据）**：
  - 🔍 *Task-Level Model-Merging Collapse*（2026-03）：某些任务组合在**所有**合并方法下一致崩塌 → **崩塌是任务对的固有属性，不是方法缺陷**。归因反直觉：**表征不兼容**强相关，而参数空间冲突指标（方向/符号冲突、delta 重叠）**几乎不相关** → TIES/DARE 那类"消解参数干扰"的思路**诊断错了病因**。
  - 🔍 *Why Do More Experts Fail?*（2025）：用高斯宽度证明合并存在**解析上界**，新增专家边际收益**严格凹**并迅速饱和。**知识条数不是线性可加的。**
- 🔍 **DARE**（ICML 2024）：可丢弃 90–99% 的 delta 参数而能力几乎不损（SFT delta 值域极小、极度冗余）。**适用边界**：只对小幅 SFT delta 成立；继续预训练/强 RL 的大 delta 下失效。

### L. 知识蒸馏（teacher → student）🔍

| 四问 | 答案 |
|---|---|
| 内化到哪里 | 稠密权重（少数变体到适配器） |
| 写入算子 | 梯度 |
| 持久性 | ✓ 永久 |
| 准入门控 | **教师分布**（off-policy 时为固定语料 → 无在线门控，这正是误差累积/暴露偏差的来源） |

- 🔍 **On-Policy Distillation**（Thinking Machines 2025-10）★：从**学生自己**采样轨迹 → 教师对**每 token** 打分（per-token 逆向 KL 作 advantage）→ policy gradient。
  **门控 = 教师 logprob，不需要 GT、不需要外部 reward，教师即验证器** ← 与 STaR（需 GT）的分水岭。
  - 数据：8B 学生 AIME'24 60%→70% 仅约 150 步；整体**少 7–10× 梯度步、低 50–100× 算力**。
  - ★★ **最相关的一条**：Qwen3-8B 在内部文档上 mid-train 后 IF-eval **85% → 45%**（混 70% chat 数据仍只有 79%，LoRA 也救不了）；再用**原模型自己当教师**做 on-policy 蒸馏，IF-eval 恢复到 **83%** 且知识分 **36%→41%**。
    → **"先写入新知识、再用自蒸馏修复被干扰的旧能力"是本族对"内化而不遗忘"最直接的工程答案。**
- 🔍 已 scale：Gemma 2、Qwen3 等技术报告已采用；2026-04 有专门综述把 OPD 形式化为 f-散度最小化。

### M. 检索增强 / 训练期检索内化 🔍 —— "何时该写进权重"的判据双轴

- 🔍 **经典锚点**：Ovadia et al.（EMNLP 2024）——非监督微调**学不进新事实**，RAG 稳定更优，**且 RAG 单用甚至优于 RAG+微调**；
  **但**：训练中暴露同一事实的**大量改写变体**可缓解。
- 🔍 **2026 翻转**：*Synthetic Mixed Training*（2026-03）用 **Focal Rewriting**（以问题为条件改写文档）把上条经验规模化 → QuaLITY 上**相对超过 RAG 4.4%**，与 RAG 结合 **+9.1%**，且随数据量/生成器强度**对数线性改进**。
  > **结论修正：不是"微调不行"，是"原文重复的微调不行"。需要以问题为条件的多样化改写**——这正是上下文蒸馏族的核心操作。
- 🔍 **判据双轴**（可直接用作写入决策）：
  - **规模轴**（*RAG-Considerate Pretraining* 标度律，2026-04，OLMo-2 30M–3B）：性能 = f(模型规模, 预训练 token, 检索库规模)；**非单调**，小模型从检索获益最大，大模型收益递减且出现**过度分配敏感性**。
  - **分布轴**（*Less Popular Knowledge*, 2024-03）：**实体越长尾，RAG 相对微调的优势越大**。
  > **合起来**：**高频 + 稳定 + 小模型 → 倾向写进权重；长尾 + 易变 + 大模型 → 倾向留在检索。**

### N. 自我改进 / 合成数据循环 🔍 —— 一条形式化的否定结论

- 🔍★ **Sharpening 机制**（Huang et al., ICLR 2025）：**自我改进不可能创造模型中原本不存在的信息**。
  它做的是 *sharpening*——利用"验证能力强于生成能力"的 gap 把概率质量集中到高质量序列，本质是**把推理期计算摊销进权重**。
  > **直接后果**：凡"写入源 = 模型自采样"的家族（STaR / RFT / self-instruct / RLAIF / self-play）在理论上都受 **coverage 约束**，只能作为**已有能力的锐化/摊销算子**。
  > **真正的新知识必须来自外部证据（上下文、教师、检索）** —— 这反向确认了**上下文蒸馏（J）才是那座桥**。
- 🔍 **STaR**（2022）：门控 = **最终答案正确性 → 需要 GT**。与 on-policy 蒸馏（教师即验证器，无需 GT）和本项目（无 GT 自验证）形成三方对照。
- 🔴 **模型坍缩，及其边界条件**：
  - 🔍 Shumailov et al.（**Nature 2024**）：递归训练自身输出 → **尾部消失、不可逆缺陷**。
  - ⚠️ **但** Gerstgrasser et al.（2024）修正：既往研究默认新数据**替换**旧数据；改为**累积**则**坍缩消失**，测试误差有**与迭代次数无关的有限上界**。
  > **坍缩不是"合成数据"的固有属性，而是"替换式自消费 + 无门控"的属性。**
  > 引用 Nature 那条时**必须连同边界条件一起标注**，否则会把过强结论写进文档。

### O. 睡眠期 / 离线计算 🔍

- 🔍 **Sleep-time Compute**（Letta + UC Berkeley, 2025-04）——**重要的否定性发现**：该族源头**并不写权重**。
  机制：拆 prompt 为静态 context + 动态 query，空闲期只对 context 做推理/摘要，产出"预处理过的 context"。
  内化到 → **外部文本工件**；持久性 → 跨会话但可删可覆盖（**可逆**）；门控 → 无 GT 校验。
  效果：同精度下 test-time token 降约 **5×**；Stateful GSM-Symbolic **+13%**、Stateful AIME **+18%**。
- 🔍★ **Language Models Need Sleep**（Behrouz et al., 2026-06，**Titans/HOPE 同一组**）：把睡眠期**正式做成知识内化机制**。
  明言现有模型"**无法把临时的 in-context 知识转成稳定的长期参数变化**"，给出两阶段：
  ① **Memory Consolidation / Knowledge Seeding**——把短期（上下文/快权重）学到的，经蒸馏 + RL 模仿转移进大网络；
  ② **Dreaming**——用 RL 生成合成数据离线反刍。
  **这是 CLS 巩固 → LLM 的最正式对应物。** 门控 → **隐式，未给出显式准入信号**。
- 🔍 **Do LMs Need Sleep?**（2026-05）：把睡眠期落到**权重**上——清空 KV 前对累积上下文做 N 次 recurrent pass，用**习得的局部规则**（非梯度）更新 SSM 快权重。
  > 🎯 **门控：论文未给出显式准入信号，只是对整个累积上下文窗口做 N 次 pass。**
  > **这个"无门控"正是压缩增益门可以直接插进去的位置。**

### P. 参数化知识库 / 神经数据库 🔍

- 🔍★ **LMLM**（NeurIPS 2025，Weinberger 组）——**机制最干净：在训练期就决定"不内化"**。
  做法：预训练时把检索到的**事实值从训练损失中 mask 掉**，教模型学会"发起定向查表"而非把长尾事实压进权重。
  > **损失掩码本身就是准入门**——被 mask 的值不进权重。
  结果：以远小的规模取得可比表现，同时获得**显式、可编辑、可验证的知识库**，并支持 **instant forgetting**（删除特定事实而不损通用能力）。
  → **直击可逆性与隔离性**：知识写在人类可读 KB 里，删除=删行，天然按条目可撤销、可按对话者分区。
  续作 Co-LMLM（2026-07）放宽模板约束。
- 🔍 **PRAG / DyPRAG**：把语料编译成 **per-document LoRA** 的参数化知识库；DyPRAG 用轻量 hypernet 把文档 embedding **前向映射**成 LoRA。
  限制：PRAG 每文档训练+存储开销大；**DyPRAG 的 LoRA 平均在多文档聚合时互相干扰**。
- 🔍★★ **Generative Adapter**（Microsoft, **ICLR 2025**）—— **对本项目最关键的一篇**：
  给冻结 LM 配一个自监督训练的 adapter generator（hypernetwork），上下文经基座编码后**直接产出逐层加性 delta 权重，全程只用前向传播、不做任何梯度下降**；双线性 + 流式增量更新，上下文可边来边累积进权重。
  | 四问 | 答案 |
  |---|---|
  | 内化到哪里 | 适配器 / 加性权重增量 |
  | 写入算子 | **前向摊销映射**（近似闭式，**非梯度**） |
  | 持久性 | **✓ 跨会话，且天然按对话者隔离**（每用户一份 delta） |
  | 准入门控 | 🔴 **无——凡进上下文即写** |

  效果：多轮会话记忆用户信息上比全量历史 prompt **省 4× 计算与内存**。
- 🔍 **Memory Grafting**（2026-05）：用"嫁接模型"**离线前向**计算高频 n-gram 的隐状态存为记忆值，推理时**精确最长后缀匹配**检索。是把检索从**文本层下沉到隐状态层**的半内化形态，也是睡眠期计算在预训练侧的落地。限制：精确匹配泛化差、记忆表随语料线性增长。

### 🔴 跨 J/O/P 的家族级共同缺口 🔍

🔍 *Rethinking Continual Experience Internalization*（2026-06）直接研究"把 agent 的上下文经验转成可复用参数化能力"，报告核心失败模式：
> **多轮迭代内化下出现 progressive capability collapse（能力逐步坍缩），而非复利式改进。**

三条可操作结论：**principle-level（抽象策略）比 instance-level（具体轨迹）更耐久**；**step-wise 插入优于 global injection**；**从高质量 teacher 做 off-policy 比 on-policy 更稳定**。

> **但它没有给出决定"写不写"的门控信号——这一空缺在本轮检索到的上下文蒸馏、睡眠期、参数化知识库工作中反复出现，是一个家族级缺口。**

## §5 五个根本张力

### 5.1 稳定性—可塑性（stability-plasticity）
要学新东西就得改权重，改权重就毁旧知识。**规模上真的没解。** 所有方案都是缓解：replay、正则化、参数隔离、稀疏化。

### 5.2 叠加（superposition）→ 不可寻址
事实不在可定位的槽里，而散布在多义神经元上 → 改一个有涟漪 → 顺序编辑崩溃（ROME 10–20 次）。
**稀疏可寻址（E 族）是目前唯一有定量抗干扰证据的解法**（89%/71% → 11%）。

### 5.3 内化度 ↔ 可逆性/可隔离性 反比 💭
见 §1.2。**"永久"不该等于"不可逆"**——外部记忆删条目 trivial，权重里删除极难（机器遗忘/unlearning 是独立难题）。

### 5.4 容量上界
- 循环状态：正交 KV 对数 ≤ 模型维度，超出即碰撞 ⚠️
- 联想记忆：经典容量界
- 稀疏槽：上界与崩溃形态**完全未知**（1000 条未崩，10⁴？10⁵？）

### 5.5 隔离 vs 泛化
有些 per-user 学到的东西**应该**泛化给别人。"哪条该留在本地"本身是个判断问题，且**在架构文献中几乎未被提出**——
✅ 8 篇一手架构论文中 `user`/`users`/`speaker`/`interlocutor`/`per-user` **命中全为零**。

## §7 本项目在全景中的位置

**[Learning in Referencing](RESEARCH_LEARNING_IN_REFERENCING.md)** 攻的是 §6 中**最未被占据的那一格**：

> **环节 ②（准入门控）× 信号类型（无 GT 概念正确性）× 基质（参数/架构级巩固）**

### 🔴 第五轮带来的定位修正（**结论：更有利，但声明必须改**）

**必须撤回的说法**：~~"推理期写入与跨会话持久从未同时成立"~~ —— 🔍 **家族 J（上下文蒸馏）已经做到了**，
其中 **Generative Adapter**（ICLR 2025）甚至做到 **单次前向写入 × 跨会话 × 天然按用户隔离**。

**但这反而让定位更好、而非更差**——因为整个 J 族（以及 O 睡眠期、P 参数化知识库）**都没有准入门控**：

| 家族 | 有什么 | 缺什么 |
|---|---|---|
| 🔍 J 上下文蒸馏 | 上下文知识 → 永久权重的完整转换 | 🔴 **凡进上下文即写，无门** |
| 🔍 J′ Generative Adapter | 单次前向 + 跨会话 + 按用户隔离 | 🔴 **无门** |
| 🔍 O 睡眠期（写权重版） | 离线巩固落到快权重 | 🔴 **整窗口 N pass，无门** |
| 🔍 P 参数化知识库 | 可编辑、可删除的知识载体 | ◐ 门是"是否可外化"，非"是否正确" |

> ### 🎯 因此本项目的贡献声明从"提出新架构"收紧为——
> **给一个已经跑通的内化管线补上它唯一缺的那个器官：一个无需标准答案的正确性门。**
>
> 这比原来的声明**更强、更可辩护、也更省事**：不必自证整条管线可行（J 族已证），只需证明**加了门比不加好**。
> 🔍 *Do LMs Need Sleep?*（2026-05）的调研记录甚至直接点出："**这个「无门控」正是压缩增益门可以插进去的位置**"。

### 🔴 第五轮带来的两个新风险（必须在实验里处理）

1. **内化不幂等**（🔍 *When Context Returns*）：把原始上下文重新塞回已内化的模型，**性能反而变差**，甚至在它本已答对的样本上退化。
   → 本项目是典型的"引用 → 内化"系统，**必须测这一条**；已知的轻量修复是 `stop-gradient anchoring + forward KL 一致性正则`。
2. **迭代内化会能力坍缩**（🔍 *Continual Experience Internalization*）：多轮内化下 **progressive capability collapse**。
   → 缓解线索：**principle-level 优于 instance-level**、**step-wise 优于 global**、**off-policy from good teacher 优于 on-policy**。
   → **这恰好是"门"的用武之地**：坍缩的直接诱因是无差别写入（与 N 族模型坍缩的结论同构——坍缩是"**替换式自消费 + 无门控**"的属性，不是合成数据的固有属性）。

### ★ 一条理论上的正面支持 🔍

*Sharpening 机制*（Huang et al., ICLR 2025）证明：**自我改进不可能创造模型中原本不存在的信息**，
凡"写入源 = 模型自采样"的家族都受 coverage 约束，只能锐化已有能力。
> **真正的新知识必须来自外部证据（上下文 / 教师 / 检索）。**
> → 这从理论侧**确认了本项目的问题设定是对的**：新概念必须**在引用中从对话者那里获得**，而不可能靠模型自己想出来。

### 已验证的部分（[P0 实证](../research/learning-in-referencing/p0/README.md)）

| 结论 | 数据 |
|---|---|
| **压缩增益能分开"真意 M"与"误解 M′"** | 22 items，margin **+4.08 nats** 95%CI[+2.52,+5.70]，**19/22, p=0.00043** |
| **但观测量必须是"用词决策序列"**，不是自由陈述 | 自由陈述 +0.68 (p=0.36) → 决策序列 **+4.92 (p=0.0039)**，7.2× |
| **零分布 z 校准有效**，且预测精确成立 | M′ 平均 −0.22 vs 零分布中心 −0.27（**差 0.05 nats**）；AUC 0.797→0.906 |
| 🔴 **门的判别力继承自基座能力** | **ρ(能力探针, margin) = +0.857**，校准救不了 |
| 🔴 **作用域受概念类型限制** | G2 范畴/G3 材料 **AUC 1.000** ≫ G1 合取 0.861 ≫ **G4 论元顺序 0.562 ≈ 随机**（已归因为基座能力边界） |
| ✅ **但门能「知道自己判不了」** | GT-free 可判定性计 **σ_null** → **三态门**（接受/拒绝/**弃权转追问**）：AUC **0.857→0.964**，**正确接受 M 15/15 零漏拒**，覆盖项准确率 **90%**；★ **被弃权项 AUC 0.551 ≈ 随机 → 弃权是对的，不是在丢信号** |

### 与本文档其他家族的组合关系 💭

本项目的三层架构提案**不是新家族，而是把已有家族的器官拼起来 + 补上缺的门**：

```
L1 情景记忆  ← 借 D 族（TTT/Titans 推理期写入路径）+ E 族（product-key 稀疏槽）
⚙️ 巩固门     ← 【原创】σ_null 可判定性闸门 → 压缩增益 + 跨时间稳定 + EIG 收敛
                 三态：ACCEPT / REJECT / ASK（弃权转追问）
L2 巩固核    ← 借 E 族（低频稀疏记忆层）+ HOPE/CMS（频率分层）+ F 族（per-user 隔离）
```

**边界声明（必须写进论文）**：压缩增益验证的是**对该对话者用法的语义保真度**，不是**世界真值**——
它解决 **E1（模型误解 / gavagai）**，**不解决 E2（老师说假话）**；后者属 B 族的 provenance 门（Write-Time Gating / TRUSTMEM）射程，**两者正交可组合**。
