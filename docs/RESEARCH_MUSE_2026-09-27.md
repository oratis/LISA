# Muse 调研与 LISA 产品决策

日期：2026-09-27。LISA 对照基线：`274f535`（main，v0.26.1）。研究对象暂按 Meta Muse（2026-09 发布的 personal agent）识别；如果需求中的 muse 指另一项目，需要重新界定，不能将同名 GitHub 项目当成官方源码。

## 产品研究

**官方描述：** Muse 面向日常个人事务，接受目标后持续工作，用户关闭手机也可继续；需要用户决定时再通知。发布覆盖美国的 iOS、Android、web，并提供连接服务、浏览器任务与购买确认。公告提到免费使用与订阅，但本次没有核实各档当前价格、额度或中国区可用性，不能作为 LISA 定价依据。

**设计资料描述：** 主对话承载持续关系，side chats 分开上下文；Goals 展示长期任务及计划，Ideas 帮助用户发现用途；活动记录、权限和可编辑记忆提供可见性。成果可以是文档或交互页面，批准/拒绝使用确定性的控件。

**对 LISA 的判断：** 真正值得借鉴的是“交代事情 → 看见进度 → 得到成果 → 必要时确认”的闭环。LISA 当前首页以 mood、desire、agents 为主，对开发者熟悉，对普通用户却难回答“今天能替我做什么”。应保留人格与记忆作为体验层，把任务入口、当前连接位置、执行限制和恢复动作放在前面。

## 技术与信任研究

**安全资料描述：** 每用户有专属云 VM；执行容器与权限、凭据服务分隔，Sentinel 管理连接器与网络出口，凭据在边界按需注入。浏览器控制通过代理限制能力，支付等敏感动作使用绑定具体范围的批准。推出时的隔离不代表运营方无法访问；Confidential VM 是后续计划。模型训练存在退出选项，不能概括成“默认不训练”。这些都是供应方声明，仍需独立验证。

**LISA 对照与差异：**

| 维度 | LISA v0.26.1 证据 | 决策 |
| --- | --- | --- |
| 云执行 | `src/web/tenant-runtime.ts`、`tenancy.ts`、`src/cloud/turn-lease.ts` | 当前为租户作用域与共享服务，绝不能宣称等价于每用户独占 VM |
| 权限 | `src/web/capabilities.ts`、`src/runtime-policy.ts`、`src/approval.ts` | 保留后端强制边界；客户端按模式解释不可用能力 |
| 云工具 | `src/tools/registry.ts` 的 cloudSafeSubset | 不为展示“全能助手”开放主机 shell 或远控路由 |
| 记忆/人格 | `src/memory/`、`src/soul/`、`src/knowledge/` | 作为可查看的连续上下文；不承诺两个实例已自动同步 |
| 后台 | `src/heartbeat/`、`src/web/autonomy-sweep.ts` | 需要服务端调度实际在线；手机被关闭不等于系统具备无限后台执行 |
| 本地连接 | iOS `AppState`、Keychain、`src/web/pairing.ts` | 云账号与 Mac 设备授权分开，不能用云 token 直接授权任意 Mac |
| 结果/任务 UI | iOS `ChatView`、`HomeView`、`RosterView` | 优先完善普通任务起点、草稿交接和模式隔离；通用持久任务引擎需要单独设计 |
| 商业化 | `src/billing/`、iOS StoreKit | 内购入口不能依赖额度请求成功；消费品不可伪装成可恢复订阅 |

## 关键用户路径

1. **首次使用**：清楚说明 AI personal assistant，直接进入官方云登录；连接自己的 Mac 是同级的可选路径。官方云域名为默认值，自托管地址归入高级设置。
2. **一个应用，两种运行位置**：分别保存 Mac 与 Cloud 连接。切换位置必须重置旧会话视图、停止旧流，禁止把云聊天历史或 bearer 发给 Mac。界面持续显示实际位置。
3. **交代日常任务**：先提供规划一天、起草内容、整理思路等确实可用的入口；入口只填入可编辑草稿，不替用户偷偷发起动作。
4. **连接本地 Mac**：在本地安全配对后才开放 agents、mail、sense 等主机能力；离开局域网给出网络恢复路径。无 Mac 的用户应能完成云登录和核心聊天。
5. **可信完成**：展示工具、错误、重试、取消和实际成果。支付、发信、凭据授权等不能靠一句“全部自动处理”绕开产品自身的许可模型。

## 不应照搬的部分

- 外观相似不能解决 LISA 的 4.1(a) 历史；使用自己的品牌、图标与事实准确的商店文案。
- 没有 VM/出口代理基础设施时，不宣传同等级安全。先保持 cloudSafeSubset，再规划独立执行隔离与凭据代理。
- 不把本地 Mac 连接等同于云记忆同步。账户可中心化，执行数据与设备授权仍需边界。
- 不将隐藏功能或仅审核可见的假演示当作审核修复。提供真实且稳定的审核账号、真实 StoreKit 和明确操作说明。

## 成功指标与后续实验

本次未采集真实用户行为，不能虚构转化率。建议从自愿、最小化、无聊天正文的事件开始测量：首次成功登录率、首次有效回复率、模式切换恢复率、任务完成/取消率、支付到账率、审核路径成功率。先建立基线，再给数值目标。

长期方向：持久任务状态与结果、连接器读写权限、主对话与独立任务上下文、可导出/删除的记忆、通知价值判断。这些需要端到端产品与运维验收，不能以新增一个入口宣告具备 Muse 的全部能力。
