# 压缩增益巩固门 — 机制设计

> **定位**：本文档把 [RESEARCH_LEARNING_IN_REFERENCING.md](RESEARCH_LEARNING_IN_REFERENCING.md) §9.3.1 的 **C2/C4**（论文的心脏）从一句话展开成可实现、可证伪的规格。
> **一句话**：一个新习得的概念，只有当**把它并入该对话者的持久知识后、显著降低其后续输入的描述长度**时，才够格被永久固化。

- **状态**：✅ **核心信号已由 [P0 实验](../research/learning-in-referencing/p0/README.md)验证**（8/8, p=0.0039）——但**观测量已按实测修正**（§1.2b），**单候选阈值仍未解决**（§1.3 警告）
- **最后更新**：2026-07-28
- **理论地基**：Delétang et al., *Language Modeling Is Compression*（ICLR 2024, arXiv:2309.10668）——预测器 ≡ 无损压缩器
- **前置阅读**：研究文档 §3.4（无 GT 自验证）、§7.6（十类代理表）、§9.3（立论包）

## §0 ⚠️ 先修一个会被一击致命的措辞问题

研究文档 §9.3.1 的 **C4 写的是**："拒绝**自信且一贯错误**的概念"。

**这个措辞是错的，必须收紧。** 因为它没区分**谁错了**。展开成四种错误，压缩门的行为完全不同：

| 编号 | 错误类型 | 谁错了 | 压缩增益 | 门的行为 | 是否符合预期 |
|---|---|---|---|---|---|
| **E1** | **误解（gavagai）** | **模型**：假设 ≠ 老师本意 | **低**（错误假设预测不了老师后续用法） | **拒绝** | ✅ **这是我们要赢的点** |
| **E2** | **老师说假话** | **老师**：一贯地教一个与世界不符的概念 | **高**（模型确实学对了老师的用法） | **接受** | ⚠️ **设计使然，不可能靠压缩解决** |
| **E3** | **自生幻觉** | 模型凭空发明未被教过的概念 | **低**（在留出轮次上无预测力） | 拒绝 | ✅ |
| **E4** | **噪声/一次性** | 偶发、非系统 | 低 / 撞不满 k 次 | 拒绝 | ✅ |

### 因此，诚实且更锋利的主张是

> **压缩增益验证的是"对该对话者用法的语义保真度（usage fidelity）"，不是"世界真值（world truth）"。**
> 它解决 **E1（指称欠定 / gavagai）**，**不解决也无法解决 E2（老师说假话）**。

**这是加强，不是削弱**，四个理由：

1. **防审稿人反例**：审稿人一定会构造 E2 反例（"老师教它 2+2=5，你的门照收"）。**主动划界比被击穿好。**
2. **与最锋利的近邻正交、可组合**：Write-Time Gating（来源信誉）与 TRUSTMEM（对源忠实度）做的正是 **E2 那一侧**；我们做 **E1 那一侧**。**两者正交，可叠加**——这反而让"信号维度"的贡献更清晰。
3. **直接闭合哲学线**：研究文档 §3.7 指出，Quine 的 gavagai 说明**纯分布信息下指称本质欠定**。**压缩增益正是"收敛到该对话者所指"的可计算操作化**——E1 恰恰就是那个被哲学界点名的硬问题。
4. **语义熵在 E1 上必失分**：一个**被稳定持有的误解**是**低熵**的（自洽但错），语义熵接受、压缩门拒绝。**这就是独赢点。**

> **写进论文时 C4 应改为**：拒绝"模型**自信且一贯地误解了教学内容**"的概念（E1），而非"拒绝一切错误概念"。

## §1 形式化

### 1.1 记号

| 符号 | 含义 |
|---|---|
| `p_θ` | **冻结**的基座 LM（不做梯度更新） |
| `u` | 对话者（interlocutor），隔离单位 |
| `K_u` | u 的已毕业持久知识 |
| `c` | L1 中待毕业的候选概念 |
| `T_u(c)` | **教学轮次**：c 被教/被用到的历史轮次 |
| `H_u(c)` | **留出轮次**：`T_u(c)` **之后**、且**未参与**形成 c 的 u 的后续输入 |
| `L(c)` | c 自身的编码长度（模型描述成本） |

### 1.2 两部分编码（MDL）

> **必须用两部分编码，否则门会退化成"鼓励死记硬背"。**

```
DL(H | K)      = Σ_{x∈H} −log p_θ(x | K)
DL(H | K ∪ c)  = L(c) + Σ_{x∈H} −log p_θ(x | K ∪ c)
```

**压缩增益**：

```
G(c) = [ Σ_{x∈H_u(c)} −log p_θ(x | K_u) ] − [ Σ_{x∈H_u(c)} −log p_θ(x | K_u ∪ {c}) ] − L(c)
```

即：**概念必须自己挣回它的编码成本**（Occam）。去掉 `L(c)` 项，门会接受任意多条冗长的记忆片段。

### 1.2b 🔴 观测量：压缩**决策序列**，不是自由陈述（P0 实测修正）

> **这一条是 [P0 实验](../research/learning-in-referencing/p0/README.md)打出来的，原设计漏了它，且漏掉会让整个机制失效。**

**错误做法**（P0 朴素版）：在老师的**自由陈述**（"The red box is kirel."）上算 NLL。
**实测结果**：预测力 margin 仅 **+0.68 nats（5/8, p=0.36 不显著）**，**词级 margin +0.02 ≈ 零**。
`G` 表面上 8/8，但 **92% 的 margin 来自长度罚 `L(c)`**——赢在 M 字符串更短，与概念真伪无关。

**原因**：自由陈述的熵绝大部分是**句法与措辞**（nuisance entropy），概念真伪只占极小一部分，被彻底淹没。
且 P0b 探针证明**模型有能力**区分 M/M′（落差 0.295, 6/8）——**信号存在，是观测量选错了**。

**正确做法**：压缩对象换成老师的**用词决策序列** `y_o ∈ {applies, ¬applies}`：

```
G(c) = Σ_{o∈H} [ −log P(y_o | o, K) ] − Σ_{o∈H} [ −log P(y_o | o, K ∪ c) ] − L(c)
```

> **概念要解释的正是这串决策，不是句子的措辞。**
> 实测：margin **+0.68 → +4.92 nats（8/8, p=0.0039）**，安慰剂对照 6/8 → **8/8**，长度罚占比 92% → 60%。

### 1.3 安慰剂对照（关键，控制"加任何文本都会降 ppl"的混淆）

**只看 `G(c) > τ` 是不够的**——往上下文里塞**任何**相关文本都可能降低困惑度。因此判据必须是**相对安慰剂的**：

```
G̃(c) = G(c) − max( G(c̃₁), …, G(c̃ₘ) )
```

其中 `c̃ᵢ` 是**安慰剂概念**：与 c **表面形式相似、语义为空或错位**（打乱绑定、替换指称、同长度伪概念）。

> **接受条件**：`G̃(c) > τ_gain`，即**真概念必须显著优于最好的安慰剂**。
> 这一条把"压缩门"从一个易被质疑的启发式变成**有对照的统计判据**——审稿人问"是不是加什么都能降 ppl"，这就是答案。

> 🔴 **P0 实测：阈值形式只在【基座有能力的概念类型内】成立。**
> **排序器**用法（同概念候选间择优）：22 items **19/22, p=0.00043** ✅
> **单候选阈值**用法：全部 5 类歧义混合 **AUC 0.857 ❌ 不可分**；但**仅 G2/G3（范畴、材料）时 AUC 1.000 ✅ τ=+0.75**。
> → 这不是纯方法缺陷，而是一个**作用域条件**：详见 [P0 §6](../research/learning-in-referencing/p0/README.md)。

### 1.3b ★ per-item 校准：用零分布 z 分数（P0 实测有效但不充分）

单候选阈值需要 per-item 校准。**有效做法**：把安慰剂池当成该 item 的**零分布**，

```
z_i(c) = ( ΔNLL_i(c) − μ_i^null ) / σ_i^null
```

零分布必须含 **overspec（M ∧ 额外条件，与 M′ 同构）** —— 只有这样 M′ 才会成为零分布的典型成员。
**实测该预测精确成立**：M′ 平均 **−0.22** vs 零分布中心 **−0.27**（**仅差 0.05 nats**），而 M 为 **+3.86**（显著离群）。
AUC 提升 0.797 → **0.906**。

> **与先例的关系**：这与 **SEMA**（研究文档 §7.6 中族 4 最接近的先例）用的是**同一套 z 分数校准机制**——
> 差别只在**信号类型**（SEMA 用表征新颖性，我方用正确性）。**可以正面引用为方法继承，同时凸显 delta。**

### 1.4 完整毕业判据

```
graduate(c) ⟺  G̃(c) > τ_gain                    # 压缩增益（核心 · 充分性来源）
            ∧  hits(c) ≥ k                       # 跨足够多次交互（抗 E4 噪声）
            ∧  |H_u(c)| ≥ n_min                  # 估计量最低 token 预算（控方差）
            ∧  SE(c) < τ_ent                     # 跨时间稳定性（语义熵 · 必要非充分）
            ∧  EIG(c) < τ_eig                    # 主动追问已收敛（epistemic 不确定性低）
```

> **注意各项的逻辑地位**：只有**压缩增益是"正确性"信号**；语义熵与 EIG 是**必要非充分**的守门项（自洽、问清楚了），单独都不足以判对错——这正是研究文档 §3.4 的核心结论。

### 1.5 伪代码

```python
def consolidation_gate(uid, c):
    H = heldout_turns(uid, after=c.teaching_turns)      # ⚠️ 必须是留出轮次
    if len(H) < N_MIN or c.hits < K_HITS:
        return DEFER

    base = nll(H, ctx=K[uid])
    with_c = nll(H, ctx=K[uid] | {c}) + code_length(c)  # 两部分编码
    gain = base - with_c

    placebo = max(nll(H, ctx=K[uid]) - (nll(H, ctx=K[uid] | {p}) + code_length(p))
                  for p in placebos(c))                  # 安慰剂对照
    if (gain - placebo) <= TAU_GAIN:
        return REJECT
    if semantic_entropy(c) >= TAU_ENT:   return DEFER    # 不稳定 → 再等
    if epistemic_uncert(c) >= TAU_EIG:   return ASK      # 未收敛 → 继续追问
    return GRADUATE                                      # → L2[uid]，唯一写永久层的路径
```

**三个必须遵守的实现约束**：

1. 🔴 **`H` 必须是留出轮次**。用教学轮次算增益 = 自己压缩自己，**必然虚高**，是本设计最容易犯的致命错误。
2. 🔴 **`L(c)` 不可省**，否则退化为鼓励记忆冗长片段。
3. 🔴 **安慰剂对照不可省**，否则无法回应"加任何文本都降 ppl"。

## §2 为什么现有门控在 E1 上都会失分

**这张表就是实验要打出来的结果**（对应研究文档 §7.6.2 的十类代理）：

| 门控 | 信号 | 在 E1（稳定的误解）上的行为 | 为何失分 |
|---|---|---|---|
| **语义熵**（Nature'24） | 自洽/不一致 | **接受** ✗ | 稳定持有的误解是**低熵**的；作者本人承认抓不到"一贯错误" |
| **SAGE**（几何新颖度） | s_vMF 新颖度 | **接受** ✗ | 误解往往**更新颖**（不与已有记忆重合）→ 反而优先 ADD |
| **Surprise 门**（2606.03787） | 贝叶斯惊奇 | **接受** ✗ | 惊奇 ⟂ 真伪；误解常伴随高预测误差 → 更容易写入 |
| **TRUSTMEM** | 对源忠实度 | **接受** ✗ | 模型忠实转录了老师的话，**只是理解错了**；忠实 ≠ 理解正确 |
| **Write-Time Gating** | 来源信誉 | **接受** ✗ | 来源可信；错在**接收端**，provenance 看不见 |
| **CN-DPM** | DP 先验 × 似然 | 接受 ✗ | 似然高即收；且方向相反（poor-fit 才扩容） |
| **压缩增益（本方案）** | **对留出用法的预测力** | **拒绝** ✅ | 错误假设**无法预测老师后续如何使用该概念** |

> **独赢点的单句表述**：**误解可以是自洽的、新颖的、令人惊奇的、忠实转录的、来源可靠的——但它无法预测老师接下来怎么用这个词。**

## §3 失败模式与缓解（诚实清单）

| # | 失败模式 | 后果 | 缓解 | 残余风险 |
|---|---|---|---|---|
| 1 | **E2 老师说假话** | 假概念被固化 | **不在本机制射程内**——与 provenance 门（Write-Time Gating）组合 | ⚠️ **设计边界，论文必须显式声明** |
| 2 | **高频虚词混淆** | 无意义但高频的模式压缩得好 | `L(c)` 惩罚 + 要求**组合泛化**到未见搭配 | 中 |
| 3 | **死记硬背而非泛化** | 查表式压缩 | 增益必须在**未见组合**的留出轮次上成立 | 中 |
| 4 | **用户话题漂移** | 增益估计噪声大 | `k` 次命中 + EMA + `n_min` token 预算 | 低 |
| 5 | **估计量方差** | 小 `H_u` 下阈值不稳 | 最低 token 预算；bootstrap CI 而非点估计 | 低 |
| 6 | **投毒/gaming** | 攻击者构造"高压缩"输入骗取固化 | uid 硬分区限制爆炸半径 + 写入速率限制 | ⚠️ 见研究文档 §3.6 |
| 7 | **`L(c)` 不可比** | 不同表示下编码长度尺度不一 | 固定概念表示模板；只比同模板 | 低 |
| **8** | 🔴 **基座在消歧实例上无能力** | **增益退化为噪声，门读不到任何信号** | 前置能力探针；无能力时提高门槛或转为追问 | ⚠️ **P0 实测最大约束**，见下 |
| **9** | 🔴 **关系类概念（论元顺序）** | **定义几乎不改变预测**（\|ΔNLL\| 0.90 vs 其他 4.74）→ AUC 0.562 ≈ 随机 | **P0f 已排除提示格式与变量绑定**（三种呈现全失败；显式角色说明反使 margin 转负 −0.56）→ 需更强基座 | ⚠️ **坐实为基座能力边界，作用域必须写清** |

### ★ 前置条件 2（P0 实测新增）：门的判别力继承自基座能力

> **ρ(能力探针落差, 判别 margin) = +0.857**。探针失败组 margin +2.11，通过组 **+5.86（2.8×）**。
> **校准无法弥补能力不足** —— 试过 6 种归一化，全局可分性都没救回来。
> **作用域**：属性/范畴/材料类概念上强（AUC 0.86–1.00）；**关系类几乎随机**。论文必须把作用域写清，不可泛化声称。

## §4 消融矩阵（论文的实验骨架）

| 消融 | 去掉什么 | 预期结果 | 证明了什么 |
|---|---|---|---|
| **A0 全量** | — | E1 上 AUC 最高 | 主结果 |
| **★ A0′ 必报项** | 拆开报 `ΔNLL` 与 `G` | 二者之差 = 长度罚贡献 | 🔴 **不拆开报就可能是假阳**——P0 里 `G` 8/8 但 92% 来自长度罚 |
| **★ A0″ 观测量** | 决策序列 vs 自由陈述 | 决策序列 margin 高 7.2× | P0 实测；见 §1.2b |
| **A1 −安慰剂对照** | `G̃ → G` | 假阳升高 | 对照项必要（回应"加什么都降 ppl"） |
| **A2 −`L(c)`** | 两部分 → 单部分 | 接受冗长记忆片段 | MDL 必要 |
| **A3 −留出（用教学轮次）** | `H → T` | 增益虚高、E1 也被接受 | **留出是最关键约束** |
| **A4 −语义熵/EIG** | 只留压缩 | E4 噪声穿门 | 守门项的作用边界 |
| **A5 门 off** | 无门 | 旧能力崩塌 + 污染固化 | 门本身的价值 |
| **B1 三臂对照** | 压缩 vs 语义熵 vs EIG | 见 §2 表 | **C4 独赢点** |
| **B2 vs SAGE** | τ 路由换成压缩分数 | SAGE 在 E1 上 ADD 率显著更高 | head-to-head |

**主指标**：**E1 判别 AUC**（接受 M / 拒绝 M′）。
**次指标**：组合泛化准确率、跨用户泄漏率（对标 PersistBench 53%）、N 次顺序写入后的旧能力保持曲线。
