## 1 设计与诚实定位

```
logits = lm_head( h + m(h) )      h = post-norm 最后位置隐状态（一次前向缓存，无梯度）
m(h)   = uid 分区内 top-k 稀疏槽的加权值
```

**为何可在单机训练**：记忆挂在**最后一层之后**，梯度只过冻结的 `lm_head`，**不反传任何 transformer block**。

> 🔴 **必须写明的弱化**：这是 **final-layer memory**，**不等同于**研究文档 §7.4 提议的**中间层 product-key 记忆层**。
> 它能改变输出分布，但**不参与中间层的表征计算**（结构事实）。
> **论文中不得把二者混为一谈。**
>
> ⚠️ 本段初稿在此处续写了"因此缺少深度组合性"——**已被 [P6](../p6/README.md) 实测推翻并撤回**
> （跨域组合 +0.449 且反超 L1）。**结构差异 ≠ 能力差异，不得再从架构位置推出能力限制。**

**训练信号**：老师的**用词决策**（P4 中门控放行的那些）——**不是关于概念对错的答案**。

## 2 结果

### 2.1 ★ E1 免检索（判据 I1）—— P4 未能满足的那一条

上下文里**完全没有**该概念的任何陈述，只有 `"{word} is a word in Tovi's language."`：

| 条件 | 探针 AUC |
|---|---|
| 无记忆（冻结基座） | **0.485** ≈ 随机 |
| ★ **参数化记忆（自己的分区）** | **0.992** |
| **提升** | **+0.507** |

> **⟹ 概念在参数里生效，无需任何检索或上下文注入。**
> 这是 [P4 的 L1 方案](../p4/README.md)按我方五判据**不满足**的判据 I1，现已达成。

### 2.2 E3 隔离

| | |
|---|---|
| 用**他人分区**回答自己的探针 | **0.260**（远低于随机——两义互斥） |
| 键空间分区互不相交 | **True**（构造性） |

### 2.3 ★ E4 顺序写入：分区 vs 共享（**同等总容量**）

| 已写入 | **uid 分区** 均值/最低 | **共享槽** 均值/最低 |
|---|---|---|
| 1 | 1.000 / 1.000 | 1.000 / 1.000 |
| **2** | 1.000 / 1.000 | **0.520 / 0.120** ← **第 2 次就崩** |
| 4 | 1.000 / 1.000 | 0.580 / 0.200 |
| 8 | 0.995 / 0.960 | 0.465 / **0.000** |
| 16 | **0.992 / 0.960** | **0.562 / 0.000** |
| **Δ(1→16)** | **−0.008** | **−0.438** |

> ### 🔴 但必须说清：**分区版的零退化是构造性的，不是实证发现**
> 分区不相交 + 梯度掩码 ⟹ 先前用户的槽**根本没被碰到**。
> 实测验证：**每个用户「写入时的 AUC」与「最终 AUC」逐位相同**（16/16 完全一致）。
> 曲线的 −0.008 漂移来自新用户自身分数不同（0.96 vs 1.00）拉动均值，**不是退化**。
>
> ### ✅ **有意义的结果在消融上**
> 同等总容量（16×32 = 512 槽）、只是不分区不掩码 → **第 2 次写入即崩**，
> 最终多个用户 AUC **归零（完全反向）**。
> **⟹ 防干扰的关键是【分区】，不是【容量】或【稀疏性】本身。**

## 3 两次失败（记录以免重复）

### 3.1 第一版：全词表交叉熵 → 记忆完全无效

`loss = CE(logits, target_token)` 在 **151k 词表**上——Yes/No 之差的梯度被稀释。
结果：base / 有记忆 / 用他人分区 **三者 AUC 完全相同（0.485），提升 +0.000**。

**修法**：改为直接针对决策的二元损失 `BCE(logit_yes − logit_no, label)`。

### 3.2 ★ 第二版：原始点积路由 → 记忆退化为**常量偏置**

改了损失后**仍然 +0.000**，且保持率曲线与上一版**逐字相同**——这说明记忆输出没进入排序。

**诊断（先查而非猜）**：

| 检查 | 结果 |
|---|---|
| h 是否线性可分 Yes/No | **线性探针训练准确率 1.000** → 信息**在** h 里 |
| 隐状态两两余弦相似度 | **0.9937**（近乎平行），`‖h‖ ≈ 171.8` |
| `‖W_yes − W_no‖` | **1.11** → 要改变排序需 `‖m‖ ≳ 2.5` 沿特定方向 |
| **被路由到的不同槽数** | **1 / 12** ← 决定性证据 |

> **机制**：这些提示只在"被描述的物体"上不同，隐状态近乎平行；
> 原始点积 `K·h` 被共有分量主导 → softmax **饱和成 one-hot** → 所有输入路由到**同一个槽**
> → 记忆退化为**常量偏置**，只能整体平移 logits，**无法判别**。训练 acc 卡在 0.50。

**修法**：**余弦归一化 + 温度**（`normalize(K) @ normalize(h) × 10`）。

| 路由方式 | loss | 训练 acc | 不同槽数 |
|---|---|---|---|
| 原始点积 | 0.6377 | 0.50 | 1/12 ❌ |
| `/√d` 缩放 | 0.6377 | 0.50 | 1/12 ❌ |
| **余弦 + 温度** | **0.0021** | **1.00** | 2/12 ✅ |

> ★ **这是一个值得写进论文的一般性教训**：
> **当提示只在细微语义处不同时，product-key 路由必须做余弦归一化**——
> 否则隐状态的共有分量会让路由塌缩，记忆退化为常量偏置。

## 4 ⚠️ 限制

1. **final-layer memory ≠ 中间层 product-key 层**（§1）——它**不参与中间层表征计算**（结构事实）。
   > 🔴 **本条初稿写的「因此缺少深度组合性」已被 [P6](../p6/README.md) 推翻并撤回**：
   > 跨域探针上 L4 **+0.449**（且反超 L1 +0.109），**与世界知识的组合成立**。
   > 当时那是从架构位置**推测**的，未测。
2. **分区版的零退化是构造性的**（§2.3）——**不得**报作"稀疏记忆抗崩塌"的实证。
   有意义的结论只有一条：**同等容量下，分区防住了、共享没防住**。
3. **与 ROME/MEMIT 仍非同基准对比**：判分口径（AUC vs locality/specificity）与编辑粒度均不同，仅作量级参照。
   且本轮的冲突词是**最坏情况**（互斥含义），崩得比文献报的 10–40 次快是意料之中。
4. **任务简单**：4 个互斥颜色概念，非 gavagai 对（M′ ⊂ M）的难例。
5. **I2 组合性**：✅ **P6 已测「概念 ⊗ 世界知识」并成立**；🔴 但**「概念 ⊗ 概念」仍未测**。
6. 单模型、单 seed、16 用户。

> **⟹ 按五判据：达成 I1（免检索）+ I4（持久）+ 隔离；**
> **I2 部分成立**（与世界知识 ✅，概念间未测）；**I3/I5 未测**。论文中须逐条写清。
