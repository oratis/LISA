## 1 为什么需要这个实验

**I2 的定义**（[全景文档](../../../docs/RESEARCH_KNOWLEDGE_INTERNALIZATION.md)）：**能与其它知识组合，推出从未被明说的结论。**

P0–P5 的所有探针都来自**同源微世界**——换实例但同分布。那测的是**泛化**，**不是组合**。

**跨域探针**要求两步组合：

| 步骤 | 来源 |
|---|---|
| ① `a ripe banana` 是 yellow | **预训练世界知识** |
| ② `romi` = yellow | **推理期习得的概念** |
| ⟹ `Is a ripe banana romi?` | **从未被明说**，必须把两者组合 |

**前置检查**（否则实验无意义）：模型本身是否知道这些物体的颜色 →
**阈值无关 AUC 0.891**（red 0.958 / yellow 0.917 / green 0.854 / blue 0.833）✅ 世界知识可用。

> ### 🔴 这里我错过一次，且是**同一个仪器错误的第二次**
> 初版前置检查用的是**绝对阈值**（`logit_yes > logit_no`），得 **raw 命中 0.688**，
> 脚本本身打印了 **"⚠️ 世界知识不足，跨域结论受限"**——**我却在 README 里写成了「平均命中 1.00 ✅」**。
> 两处都错：**数字错**（0.688 ≠ 1.00），**判据也错**。
>
> 判据错在哪：P3 已经查明模型对 Yes/No 题有**系统性 No 偏置**，当时就是靠改用 **AUC** 才救回来的。
> 这里复现了同一个坑——**16 个【正确】颜色配对里有 5 个 p_yes < 0.5**，
> 尽管它们与负例分得很开（负例低至 **0.001**）。改用 AUC 后 **0.891**。
>
> ⟹ **结论不变**（世界知识确实可用，P6 的跨域结果有效），但**教训要留**：
> **写进 README 的数字必须逐个回读脚本输出**；**已学到的仪器教训必须结构化进脚本，光写进报告会再犯。**

## 2 结果

| | 域内探针 | ★ 跨域探针 |
|---|---|---|
| **base**（无概念、无记忆） | 0.485 | **0.500** |
| L1 上下文注入 | 1.000 | 0.840 |
| ★ **L4 参数化记忆** | 0.992 | **0.949** |
| **L4 − base** | +0.507 | **+0.449** |
| **L4 − L1** | −0.008 | **+0.109** |

> ⚠️ base 跨域**均值 0.500 是构造性的**：每对冲突词是对称的（A 的 Yes 项正是 B 的 No 项），
> 逐用户范围 **[0.062, 0.938]** 相互抵消。这说明探针集**跨用户平衡**，不代表 base「校准良好」。

### 2.1 🔴 我方一处声明被推翻

**P5 §4 曾写**：*"final-layer memory ≠ 中间层 product-key 层——**缺少深度组合性**"*，
并据此在 Method 草稿 §6(i) 写入限制 *"we do **not** verify criterion I2"*。

**实测不支持这条**：L4 在跨域探针上 **+0.449**，且**反超 L1 达 +0.109**。

> **⟹ 「缺深度组合性」作为一条**断言**必须撤回**（它当时只是从架构位置**推测**的，未测）。
> 可保留的弱版本：**final-layer memory 不参与中间层表征计算**——这是**结构事实**；
> 但**"因此缺组合性"是未经验证的推论，且已被本实验反驳**（至少对「概念 ⊗ 世界知识」这一形态）。

### 2.2 为何 L4 反超 L1？（假说，未验证）

L1 把 `romi means yellow.` 塞进上下文，**改变了提示本身**，可能干扰模型对 `a ripe banana` 的世界知识检索；
L4 保持提示干净（只有 `romi is a word in Tovi's language.`），世界知识通路不受扰动，记忆只在输出侧移动决策。

> ⚠️ **这只是假说**，本轮未做消融验证。**论文中若引用须标为 hypothesis。**

## 3 ⚠️ 限制：本实验测了什么、没测什么

| 组合形态 | 状态 |
|---|---|
| 概念 ⊗ **世界知识**（`banana` 是黄的 + `romi`=黄） | ✅ **本实验已测，成立** |
| 概念 ⊗ **概念**（同一用户学两个概念后交叉推理） | 🔴 **未测** |
| 概念 ⊗ **否定/量化**（`not romi`、`all romi`） | 🔴 未测 |
| 多跳组合 | 🔴 未测 |

**⟹ I2 只能声称「与世界知识的组合成立」，不得泛化为「具备组合性」。**

其他：单模型、16 用户、跨域探针每人仅 8 条（4 正 4 负）、真实物体列表为人工挑选（4 色 × 4 物）。
