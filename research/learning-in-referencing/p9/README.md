## 1 P9 — 插入位置 × 跨读出方向

P8 查清 final-layer memory 学的是**读出方向**（`cos(m, W_yes−W_no)=+0.79` vs `cos(m, W_A−W_B)=+0.003`）。
直接推论：**插到中间层就不再是"平移 logits"，而是改表征，之后还有若干层去变换它。** 把它变成实验：

训练只用 **F1 Yes/No**；**F2 A/B** 与 **F3 True/False** 始终 held-out。

| 插入位置 | F1（训练） | F2 | F3 | 跨方向均值 |
|---|---|---|---|---|
| base（无定义） | 0.540 | 0.550 | 0.510 | 0.530 |
| L1 定义进上下文 | 0.960 | 1.000 | 1.000 | **1.000** |
| ★ **L7 全位置** | 0.945 | **0.935** | **0.945** | **0.940** |
| ◇ **L7@last**（只改最后位置） | 0.820 | 0.565 | 0.600 | **0.583** |
| post-norm（= P5–P8 的方案） | 0.970 | 0.555 | 0.770 | 0.663 |

### 1.1 ★ 控制条件否掉了「深度」这个解释

没有 `L7@last` 的话，「中间层 vs post-norm」**同时改了两件事**：
**深度**（其上还有 20 层去变换它）与**位置覆盖**（是否改写描述物体的那些 token）。

`L7@last` 同样在 L7、其上同样有 20 层，**只是仅改最后一个位置** → 跨方向 **0.583，比 post-norm 还低 0.080**。

> **⟹ 增益来自【位置覆盖】，不是深度。** 记忆必须改写**描述物体的 token** 的表征。

## 2 🔴 P9b — 换词控制：把上面这条结论堵塌了

§1.1 的结论恰好打开一个漏洞：既然它改写的是**物体**的表征，那它完全可能只学会了
**「给蓝色物体打个标」**，根本没绑定到那个词——三种格式全过也解释得通。

控制：训练完全不变，**只把提示里的伪词换成另一位用户的伪词**，其余一字不改。

| 插入位置 | 提示里的词 | F1 | F2 | F3 | 落差均值 |
|---|---|---|---|---|---|
| **L7** | 本词 | 0.945 | 0.935 | 0.935 | |
| | ★ 换成别人的词 | 0.930 | 0.895 | 0.935 | **0.018** |
| **post-norm** | 本词 | 0.970 | 0.555 | 0.770 | |
| | ★ 换成别人的词 | 0.975 | 0.505 | 0.765 | **0.017** |

> **⟹ 两个方案都不是「学会了一个词的含义」，而是「给一类物体加了个偏置」。**

## 3 P9c — 会不会只是**单概念设置欠定**？（两个词也不行）

一个用户只有一个词时，「w 指蓝色」与「给蓝色物体打标」在训练集上**外延完全相同**——
那个词是常量、**零信息**，梯度没有任何理由去关心它。**失败可能是设置逼出来的，而不是方法的性质。**

P7 是唯一的例外：每人学**两个**词（w1=颜色、w2=材质），同一物体在两词下标签不同。
直接测，三档换词，**全部针对 w1 的探针与 w1 的标签**：

| 提示里用的词 | F1 | F2 | F3 |
|---|---|---|---|
| w1（本词） | 0.785 | 0.505 | 0.695 |
| ★ **换成同用户的 w2** | **0.790** | 0.570 | 0.645 |
| 换成别人的词 | 0.790 | 0.515 | 0.675 |
| **own − within** | **−0.005** | −0.065 | +0.050 |

> 前置：**w2 自己的探针 0.890** —— 两个词都"学会"了，所以不是没学会导致的。
> **⟹ 两概念也逼不出词绑定。** 换成同一用户的另一个词，对 w1 标签的判别**分毫不动**。

## 4 ★ 机制：两个方案**因不同原因**失败

| 观测 | L7 | post-norm |
|---|---|---|
| 隐状态 h 换词后余弦 | 0.9988 | 0.9944 |
| **记忆输出 m(h) 换词后余弦** | **0.99998** | **0.787** |
| **路由命中槽 换词后重合率** | **1.000** | 0.957 |
| m(h) 在决策方向上的投影 | — | +1.690 → **+1.047** |
| ★★ **【正例−负例】的投影差** | — | +4.443 → **+4.327（保留 97%）** |

- **L7：路由层面就看不见那个词。** 命中同一批槽、输出逐位相同。
- **post-norm：看得见词，但只动了没用的那一半。** 整体投影确实随词漂移 125%，
  **但 AUC 只看排序**——真正对应的量是**正例与负例的投影差**，它保留了 **97%**。
  ⟹ **词只平移了偏置，没改变判别。** 与 P9b 的落差 0.017 完全吻合。

> ### 🔴 这里我差点得出相反的结论
> 只看 `m(h) 换词后余弦 = 0.787` 会判成"路由确实读到了词 ✅"。
> **是加了"决策方向上的正负例投影差"这一项才发现变化的分量与判别正交。**
> ⟹ **「输出变了」不等于「行为变了」**；度量必须对准被解释的那个量。

## 6 修法方向（**未做，不得声称已解决**）

失败的直接原因是**记忆的键取自整段提示的最后位置隐状态**，而那个位置里词的信息被物体描述淹没
（换词后 h 余弦仍有 0.994–0.999）。

可试的方向，都还没做：
1. **把键取在词的 token 位置上**，而不是整段的最后位置；
2. 训练集里**同一物体配多个词、标签不同**，逼梯度必须看词（P9c 的两词设置**方向对但强度不够**——
   两个词问的是不同属性，模型可以用一个"红或木"的分级标同时糊弄过去）；
3. 显式的**词条件路由**（把词的 embedding 拼进查询）。

⚠️ 第 2 条的失败给出一个更精确的教训：**要逼出绑定，必须让两个词在同一物体上给出相反标签**，
仅仅"标签不同"是不够的。

## 7 ⚠️ 其它限制

1. **深度曲线未测**：只跑了 L7 与 post-norm（单条件动辄 15–99 分钟），L14/L21 未做。
2. **P9c 只跑了 post-norm**；L7 的两概念版本未做。
3. 单模型、单 seed、8 用户。
4. `L7@last` 与 `L7` 的差可能还混有**记忆被调用次数**的因素（全位置版每个 token 都调用一次），
   未做等调用次数的控制。
5. §6 的三条修法**全部未做**。

工程教训：**每条件即时落盘**（P9 只在最后落盘，中断一次白跑 99 分钟）；
