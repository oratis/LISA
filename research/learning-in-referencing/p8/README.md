# P8 — I5 抗干扰 ✅ / **I3 隐式触发 ❌**：内化的是**读出方向**，不是概念

> **一句话**：概念能跨**表层句式**迁移，**不能跨读出方向**迁移。
> 这一条同时解释了 P7 为什么成立（新句式、**同**读出方向）与 I3 为什么失败（**新**读出方向），
> 并第一次给"把记忆上移到中间层"提供了**实证动机**，而不是审美偏好。

## 1 I5 抗干扰 ✅

同一批探针，上下文加三档干扰。第三档是**另一位老师的含义以文本形式出现**：
`Note: in some dialects, {word} means {对方含义}.`

| 臂 | 无干扰 | 无关长文 | ★ 冲突定义 | 冲突降幅 |
|---|---|---|---|---|
| base | 0.545 | 0.525 | **0.033** | **−0.513** |
| L1 上下文注入 | 0.988 | 0.917 | 0.912 | −0.075 |
| ★ **L4 参数化记忆** | 0.960 | **0.953** | **0.910** | **−0.050** |

> ### ★ 关键的对照在 base 那一行
> base **0.545 → 0.033**：它没有概念，那条冲突注释就是它**唯一**能拿到的定义，于是照单全收，
> 答案系统性地**反向**。⟹ **这条干扰被证明是有效的**，L4 扛住**不是因为模型没读它**。
>
> **⟹ I5 成立**，且**参数化比上下文注入更抗干扰**（−0.050 vs −0.075；无关长文 −0.007 vs −0.071）——
> 合理：干扰与概念不在同一条通路上竞争。

## 2 I3 隐式触发 ❌ —— 一个干净的负结果

不问"X 是 romi 吗"，而是**要求去用它**（训练中从未出现过的句式）：

```
komalor is a word in Tovi's language.
Tovi wants a komalor object.
(A) a large blue metal cup
(B) a small red wooden ball
Which one do you hand over? Answer A or B.
```

| 臂 | ★ AUC | accuracy | 选 A 比例 |
|---|---|---|---|
| base（伪词无定义） | 0.500 | 0.488 | **0.910** |
| L1 定义进上下文 | **1.000** | 0.988 | 0.496 |
| ★ **L4 参数化记忆** | **0.507** | 0.492 | **0.914** |
| （真英语词的先验） | **1.000** | 0.979 | 0.479 |

> **⟹ 零迁移。** 任务本身完全可解（L1 与真词先验都 1.000），参数化记忆**没有任何效果**。

### 2.1 🔴 判据在这里错过一次——**同一类仪器错误的第三次**

第一版只报 accuracy，得 0.492 并直接下了"不成立"的结论。**那个数字不可信**：
伪词条件下模型 **91% 选 A**，在这种分布上用 0.5 阈值算准确率会被偏置钉死在 0.5 附近，
**看不出底下有没有信号**。

> 这是 **P3（No 偏置）→ P6（前置检查）→ P8（A 偏置）同一类错误的第三次**。
> 更难看的是：`tools/probe_metrics.auc`（P6 之后专为此抽出来的）**当时已经 import 了，
> 却只用在了 I5 上**。⟹ 抽出工具还不够，**判据必须在每个新度量上被显式选择一次**。
>
> 改用 AUC 后结论**不变**（0.507 ≈ 0.500）——但这是运气，不是方法。

## 3 ★ 机制：不是检索失败，是**读出方向**

负结果只有查清机制才有价值。两个互斥假设：

| 假设 | 说的是 |
|---|---|
| `H_route` | 新句式的隐状态落到了**别的槽** ⟹ 根本没取到概念 |
| `H_readout` | 槽取对了，但学到的值只沿 **W_yes − W_no** 推，而行动题要 **W_A − W_B** |

| 观测 | 值 | 判读 |
|---|---|---|
| 行动题 top-4 落在**训练用过的槽**的比例 | **0.750** | ✅ 检索**取到了** ⟹ `H_route` 被否 |
| m(h) · (W_yes − W_no) | **+0.7926** | |
| m(h) · (W_A − W_B) | **+0.0027** | ← 近乎零 |
| 两读出方向本身的余弦 | −0.0265 | 近乎正交 |
| ‖m(h_act)‖ | **14.279** | **不是太小，是方向不对** |

> **⟹ `H_readout` 成立**：记忆挂在最后一层，它能学的只是**沿某个读出方向平移 logits**。
> 训练用 Yes/No，学到的就是那个方向；A/B 题要的是另一个近乎正交的方向。
> **它学到的不是概念，是"这个决策格式下该往哪边推"。**

## 4 P8b — 那"多训几种格式不就行了？"

`H_readout` 对这个显然的反驳有**可证伪的预言**：多格式训练只会学成**若干方向的叠加**，
**没训过的第三种格式仍然失败**。

三种格式，读出 token 对各不相同（两两余弦：F1·F2 = −0.027、F1·F3 = **+0.107**、F2·F3 = +0.022）：

| 臂 | F1 Yes/No | F2 A/B | F3 True/False |
|---|---|---|---|
| base（无定义） | 0.540 | 0.550 | 0.510 |
| L1 定义进上下文 | 0.960 | 1.000 | 1.000 |
| **L4 训 F1** | **0.960** | 0.555 | 0.755 ← held-out |
| **L4 训 F1+F2** | 0.902 | **0.795** | **0.645** ← held-out |

**加训 F2 之后：F2 +0.240，但 F3 −0.110、F1 −0.058。是换方向，不是累加。**

### 4.1 ★ 比裁决更有力的是这个同序关系

只训 F1，在三种格式上的迁移量**与读出方向的余弦严格同序**：

| 测试格式 | 与 F1 的读出方向余弦 | AUC | 相对 base |
|---|---|---|---|
| F1 Yes/No | 1.000 | **0.960** | +0.420 |
| **F3 True/False** | **+0.1065** | **0.755** | **+0.245** |
| **F2 A/B** | **−0.0265** | **0.555** | **+0.005** ≈ 0 |

> **⟹ 迁移量随读出方向的余弦单调变化。** 这是 `H_readout` 最直接的量化证据。
> ⚠️ **只有三个点，顺序完全一致而已——不得写成拟合出来的定律。**

## 5 这条结论如何**回溯限定** P5–P7

**P5/P6/P7 的训练与探针全部使用 F1 Yes/No 这一个读出方向。**

| 实验 | 变的是什么 | 结果 |
|---|---|---|
| P6 跨域探针 | 表层内容（真实物体） · **同读出方向** | ✅ 0.949 |
| P7 合取探针 `Is X both w1 and w2?` | **表层句式**（训练中没有的） · **同读出方向** | ✅ 0.889 |
| **P8 I3 行动题** | **读出方向** | ❌ 0.507 |

> ### ⟹ 精确的主张只能是这一条
> **概念能跨表层句式迁移，不能跨读出方向迁移。**
> 「泛化 ✅ / 组合 ✅ / 隐式触发 ❌」不是三个互不相干的结论，
> **是同一条机制的三个侧面**。
>
> 论文中 P5–P7 的每一条结论都必须加上作用域：**"在训练所用的决策格式内"**。

## 6 这给中间层记忆提供了**实证动机**

研究文档 §7.4 原本提议的是**中间层 product-key 记忆**；P5 因为算力做成了 final-layer 版本，
并（错误地）声明它"缺深度组合性"——那条已被 P6 推翻撤回。

**现在有了正确版本的那条限制，而且它是测出来的**：

> final-layer memory 只在**输出层**动手，所以它学到的东西天然绑死在**训练任务的读出方向**上。
> 要跨格式生效，记忆必须介入**中间层表征**——那里没有"读出方向"这回事。
> **⟹ 中间层记忆现在是一条有实证动机的下一步，不再只是审美偏好。**

⚠️ 但这是**预测，不是结果**。中间层版本**未做**，不得声称它能解决。

---

## 7 ⚠️ 限制

1. **I3 只测了一种新格式**（二选一行动题）。其它形态（开放生成、多轮对话中的自发使用）未测。
2. **P8b 只有三种格式、三个余弦点**（§4.1）——同序，但**不是拟合出来的定律**。
3. 加训 F2 会拉低 F1/F3，我方猜测是**槽容量下的方向竞争**——**未做消融**，是假说。
4. **I5 只测了一种冲突形式**（"in some dialects" 注释）。更强的形式（老师直接改口、多轮坚持）未测。
5. 单模型、单 seed。
6. **中间层记忆未实现**（§6），不得声称已解决跨格式问题。
