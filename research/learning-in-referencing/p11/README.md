## 2 ★ 两个双向控制都按预测失败——归因成立

这是本轮**唯一完全达标**的部分。两个控制各自故意破坏一条约束：

| 控制 | 破坏哪条约束 | 预测 | 实测 |
|---|---|---|---|
| **postnorm_word** | 值进 **logits** 而非表征 | 塌到 base | **F1/F2/F3 = 0.585/0.540/0.525 —— 与 base 逐位相同** ✅ |
| **emb_allpos** | 键不是**词**（在所有位置注入） | 换词落差回到 ~0.02 | 落差 **+0.075**，训练 acc **0.531**（≈只看物体的上限 0.5）✅ |

> **postnorm_word 与 base 逐位相同**：常量加在末位 = 纯 logit 平移，**不改排序** ⟹ 构造性必然。
> 它解释了**为什么 P5–P8 必须用输入依赖的路由**：词条可以是常量，前提是后面的网络替它干活。
>
> **emb_allpos 连训练集都拟合不了**（0.531）：一个加在所有位置的常量，
> 无法区分"问的是 w1"与"问的是 w2" ⟹ **键必须是词**这条约束被正面确认。

**⟹ §1 那两条约束的归因是对的。错的是"满足它们就够"。**

## 3 🔴🔴 复述控制的裁决**已撤回**——那是我方脚本的一个 bug 造成的

### 3.1 初版报告（**已作废**）

| 条件 | ‖v‖/‖h‖ | ~~复述成功率~~ |
|---|---|---|
| ~~L7~~ | 0.02 | ~~0.50~~ |
| ~~emb~~ | 1.00 | ~~0.00~~ |
| ~~emb_allpos~~ | 0.50 | ~~0.00~~ |

初版据此判「主条件的结果**不可解读**」。**该裁决作废。**

### 3.2 🔴 原因：hook 被重复注册，复述是在 **2× 注入**下测的

`p11_lexical_entry.py` 在主 hook `hd` **尚未移除**时，又在**同一个 module** 上注册了第二个
（初版 :392）。PyTorch 把前一 hook 的返回值当作后一 hook 的 `output`：

```
hook1: h  → h + v
hook2: (h + v) → (h + v) + v = h + 2v      ← 复述测的是这个
```

**隔离实验**（同一批学到的 v，L7，n=4，与 P11 同口径的 w1-only）：

| 注入次数 | 复述成功率 |
|---|---|
| **1×（正确）** | **0.75** |
| 2×（初版实际测到的） | **0.25** |

P11 初版报的 **0.50** 正落在 2× 那一侧。**修法**：复用已挂着的主 hook，不再注册第二个。

### 3.3 ✅ 更正后：复述控制**通过**

用**单次注入**、同配置（L7、8 用户、300 步）重测（见 [`p11c`](p11c_identity_loss.py) 的 λ=0 臂）：

| | 复述成功率 |
|---|---|
| **L7，λ=0，两个词平均** | **0.94** ✅（阈值 0.75） |
| L7，n=4，w1-only | 0.75 ✅ |

> ### ⟹ 三条更正
> 1. **「主结果不可解读」撤回** —— P11 的主结果**是可解读的**。
> 2. **主裁决不变**：F3 **0.775 < 0.85**，仍是**未达预注册及格线的负面结果**（该判定与复述控制无关）。
> 3. ⚠️ **P11c 的立项理由被削弱**：它的动机是"目标函数缺少身份保持项"，
>    而那个诊断建立在**这个被污染的测量**上。λ 扫描仍照跑（它能回答"身份项是否还能提升 F3"），
>    但**不得再写成"为了修复复述失败"**。

⚠️ 辩论反 3 的原措辞「拼不出 ⟹ 绑定是假的」仍然过强（换词后 AUC 0.080，**绑定行为是真的**），
这一条与本 bug 无关，独立成立。

### 3.4 ★ 这是同一类错误的第三次

| 轮次 | 控制实验自身的缺陷 |
|---|---|
| 1 | 用**随机方向**的同量级向量验证复述 ⟹ 换成学出来的 v 就崩 |
| 2 | 范数上限算在**嵌入层**而注入在 L7 ⟹ 上限小两个量级，训练卡 0.500 |
| 3 | **hook 重复注册** ⟹ 控制实验在 2× 注入下跑，裁决作废 |

**⟹ 控制实验本身也必须被控制。** 现已在脚本内加断言：注册 hook 前后打印该 module 上的
hook 数量，>1 即报错。

## 5 过程中抓到的两个我方 bug（都是控制实验抓的）

1. **复述控制的"通过"是假的**：初版用**随机方向**的同量级向量验证得 0.88 ✅；
   换成**学出来的真实 v**（同范数）→ **0.00**。
   ⟹ 范数不是正确的约束，问题在**方向**：梯度只优化决策，没有任何一项保护 token 身份。
   ★ **教训：控制实验必须用真实产物跑，不能用同量级的替身。**
2. **范数上限算错了层**：一律用**嵌入层**的 ‖h‖（1.09），但残差范数随深度增长
   （P5 实测末层 ≈172）⟹ L7 上的上限小了两个量级，训练 acc 卡在 0.500，**看着像"架构不能"**。
   修正后训练 acc 1.000，而 v 只用了隐状态范数的 **2%**。
   ★ 这是 P10 那个坑的翻版：**又一次差点把实现问题报成架构限制。**

⚠️ 实施顺序也被控制实验推翻：文档原写「先做 ℓ=0，够就不做 ℓ=7」，
而 ℓ=0 恰恰是词的身份所在的层。**是证据改的顺序，不是直觉。**

## 7 ★ F2 为什么不动——三个假设，只有一个成立

[`p11b_f2_diag.py`](p11b_f2_diag.py)：直接看 p(A) 的分布，与**上下文注入**（同格式拿到 0.905）逐项对照。

| 臂 | AUC | p(A\|正例) | p(A\|负例) | **正负例之差** | **p(A) 展幅** | 选 A 率 |
|---|---|---|---|---|---|---|
| **词条(L7)** | 0.570 | 0.534 | 0.514 | **+0.021** | **0.569** | 0.562 |
| base | 0.540 | 0.589 | 0.585 | +0.004 | 0.223 | 0.700 |
| **L1 上下文** | **0.905** | 0.487 | 0.287 | **+0.200** | 0.340 | 0.237 |

| 假设 | 判据 | 裁决 |
|---|---|---|
| `H_sat` p(A) 饱和、分辨率被吃掉 | 词条的展幅应远小于 L1 | ❌ **被否**：词条展幅 **0.569 > L1 的 0.340**，比 L1 还展得开 |
| `H_weak` 词条没迁到该读出方向 | 分布展得开但两组不分离 | ✅ **成立**：正负例之差仅 **+0.021**，而 L1 是 **+0.200** |
| `H_item` 逐用户双峰、均值有误导 | 逐用户 AUC 跨度 | ✅ **也成立**：**[0.20, 0.20, 0.32, 0.68, 0.76, 0.76, 0.80, 0.84]** |

### 7.1 相对 base 的增益 ≈ 0，且**符号逐用户翻转**

| uid | base | 词条 | Δ | L1 |
|---|---|---|---|---|
| ISO-01 | 0.20 | 0.32 | **+0.12** | 0.60 |
| ISO-02 | 0.84 | 0.68 | −0.16 | 1.00 |

| ISO-04 | 0.80 | 0.76 | −0.04 | 1.00 |

**⟹ n=8 下与 0 无法区分。** §1 表里的 0.570 vs 0.540 **不构成提升**，正文不得如此表述。

### 7.2 ★ 附带发现：**F2 作为测量仪器对非上下文方法不可靠**

**base 自己在 F2 上就是坏的**：逐用户 AUC **0.20–0.84**（两个用户系统性反向）。
而 **L1 在同样的用户上是 0.60–1.00**（7/8 ≥ 0.96）——**把定义显式放进上下文能压过基座的固有倾向，
而一个细微的词条压不过。**

> ⟹ **F3 才是更干净的仪器**（base 0.525、L1 0.995，无逐用户反向），
> 论文里跨格式的主证据应以 **F3** 为准，F2 只作为"更难的格式"报告。
> ⚠️ 但这**不改变判定**：F3 也只有 0.775，仍低于跑前写死的 0.85。
